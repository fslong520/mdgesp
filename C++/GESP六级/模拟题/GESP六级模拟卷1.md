## 第 26 题【划段得分】

### 题目描述

小杨拿到一个由小写字母组成的字符串 $s$，长度是 $n$。他可以把字符串划分成若干个连续的子串（段），要求**每一段内的任意两个字符都互不相同**（即段内没有重复字符）。

若某一段的长度为 $len$，则该段的得分为 $a[len]$。请问：在所有合法的划分方案中，各段得分之和的最大值是多少？

### 输入格式

第一行一个正整数 $n$，表示字符串长度。

第二行 $n$ 个整数 $a[1], a[2], \dots, a[n]$，$a[i]$ 表示长度为 $i$ 的段的得分。

第三行一个长度为 $n$ 的字符串 $s$，仅含小写字母。

### 输出格式

输出一行，一个整数，表示最大总得分。

### 样例输入 #1

```
5
1 10 10 10 10
ababa
```

### 样例输出 #1

```
21
```

### 样例解释 #1

划分为 `ab` + `ab` + `a`，三段长度分别为 2、2、1，得分 $10+10+1=21$。可以证明没有更优方案。

### 数据范围

- $1 \le n \le 1000$
- $1 \le a[i] \le 10^4$
- 段内字符互不相同，故每段长度至多 26，$a$ 中实际只用得到 $a[1..26]$。

## 第 27 题【分组积分】

### 题目描述

$n$ 名同学参加研学活动，需要分成若干个小组，每组人数必须**不少于 $L$ 且不多于 $R$**。若某小组恰好有 $i$ 名同学，则该组的研学效果为 $a[i]$。

请计算：将 $n$ 名同学全部划分完毕后，研学效果总和的最大值。

### 输入格式

第一行三个正整数 $n, L, R$。

第二行 $n$ 个整数 $a[1], a[2], \dots, a[n]$，$a[i]$ 表示小组人数为 $i$ 时的研学效果。

### 输出格式

输出一行，一个整数，表示最大总效果。

### 样例输入 #1

```
5 2 3
0 5 4 0 0
```

### 样例输出 #1

```
9
```

### 样例解释 #1

$5 = 2 + 3$（或 $3+2$），效果 $a[2]+a[3]=5+4=9$。

### 数据范围

- $1 \le n \le 1000$
- $1 \le L \le R \le n$
- $0 \le a[i] \le 10^4$

---

## 第 28 题【森林派对】

### 题目描述

一棵树有 $n$ 个结点，编号 $1 \sim n$，根结点为 1。第 $i$ 个结点的快乐值为 $w[i]$（可以为负）。

现在要选出若干个结点参加森林派对，要求**任意一条边连接的两个结点不能同时被选**（即不能同时选父与子）。求选出的结点快乐值总和的最大值。

### 输入格式

第一行一个正整数 $n$。

第二行 $n$ 个整数 $w[1], w[2], \dots, w[n]$。

接下来 $n-1$ 行，每行两个整数 $u, v$，表示一条边。

### 输出格式

输出一行，一个整数，表示最大快乐值总和。

### 样例输入 #1

```
3
5 1 1
1 2
1 3
```

### 样例输出 #1

```
5
```

### 样例解释 #1

选根结点 1，快乐值 5；不能同时选 2、3。若选 2 和 3，快乐值 1+1=2。故最大为 5。

### 数据范围

- $1 \le n \le 10^5$
- $-10^4 \le w[i] \le 10^4$

---

## 第 29 题【树的直径】

第一行一个正整数 $n$。

接下来 $n-1$ 行，每行两个整数 $u, v$，表示一条边。

### 输出格式

输出一行，一个整数，表示树的直径。

### 样例输入 #1

```
5
1 2
2 3

```

### 样例输出 #1

```

```

### 样例解释 #1

距离最远的两个结点为 4 和 5，路径 4-3-2-5 共 3 条边。

### 数据范围

- $1 \le n \le 10^5$
