## 一、阅读程序怎么练（本卷最弱，主攻）

### 方法 1：圈输出变量（治"认错输出"）

读程序第一件事——找到 `cout`，把输出的变量圈出来，写上"它是什么"。

> 本卷例：加法进位程序 `cout << s`——输出的是**进位次数 s**，不是和。照此法 16–20 题全可拿下。孙 19、20 选"和"，即没圈输出变量。

**练法**：本卷每段阅读题，先写"输出 = ____"再动笔。

### 方法 2：变量跟踪表 / 竖式模拟（治"不模拟"）

手写一行一变量，逐步推演，像电脑执行。

> 本卷例：加法进位列竖式，一位位数 `x+y+c≥10` 触发几次；dfs 枚举把二进制序列全列出来数。

**练法**：凡输出题，必写跟踪表，禁跳步、禁心算猜答案。

### 方法 3：反例思维（治"判断题瞎猜"）

判断题见"一定 / 必然 / 永远"，先找反例再定 T/F。

> 本卷例：18 题"输出永远 ≤ a 的位数"——找 `a=5`、`b=95`，进 2 次、s=2>1，反例成立。23 题"d>10 必崩"——字符被删、d 耗尽即不崩。17 题 5 位最多进 5 次，无反例。

**练法**：本卷每道判断题，先写"反例：____"再作答，写不出反例才判"成立"。

### 方法 4：复杂度数法（治"复杂度错"）

- 数循环层数：单层 O(n)、双层 O(n²)；嵌套 while 数"每个元素进出几次"。
- 数递归分支：每层 k 分支、深 n 层 → kⁿ。
- 无关参数不计：d 这种固定输入参数不随 n 增长，不算规模。

> 本卷例：25 题每个字符入栈 1 次、出栈至多 1 次 → Θ(n)；30 题 dfs 每层 2 分支深 n 层 → 2ⁿ 非 n²。

### 方法 5：功能一句话（治"功能/思想题"）

读完用一句话概括程序"在算什么"，再答功能与思想题。

> 本卷例：加法进位=数进位次数；删字符=删 d 个使字典序最大；dfs=递归枚举统计不含连续 1 的序列数（思想=枚举，非迭代）。

## 二、完善程序怎么练（本卷 45.5%）

### 方法 1：变量角色表

填空前先填表——每个数组/变量是干什么的。填不出表不动笔。

> 本卷例：有序对题 `num`=不同值个数、`present[x]`=x 是否出现过、`c[x]`=x 上次的计数快照、`pair`=答案。38 题错即 `present` 语义反（首次出现时 present 为 false，条件应取反）。

### 方法 2：填空三问

每填一空自问三句：**这个变量是什么？下一步往哪走？谁进结果（异或/和）？**

> 本卷例：骨牌题三问——当前格不盖，数字进不进异或（进，故异或）；盖住的格子进不进（不进，sum 不变）；处理完往哪走（右移，列尾换行归零）。41/43/44/45 四处错全由这三问解出。

### 方法 3：回溯模型（骨牌类）

```
入口 solve(0,0,0) → 边界判断 → 分情况：
  不选 → 下一步（数字计入）
  选   → 标记 covered；递归；还原标记
返回 max(各情况)
```

**练法**：本卷骨牌题按"入口→边界→分情况→标记还原"四步重填一遍。

### 方法 4：代入验证

填完所有空，取小样例手跑一遍，值突变即某空错。

> 本卷例：有序对取 `a=[1,2,1]` 手数不同值对，与程序输出对照。

## 五、做题格式示例（家长参考：孩子草稿应长这样）

以下展示孩子做**一整道阅读大题（16–20 题连题）**时，纸上应出现的完整解题过程——不是一题一题零散写，而是先把程序读懂，再连续作答。

### 完整示例：阅读程序第 1 题（加法进位，16–20）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
【第16-20题 基于以下程序】

程序：
  while (a>0 || b>0) {
    取 a、b 末位 x, y
    if (x+y+c >= 10) { c=1; s++; }
    else c=0;
  }
  cout << s            ← 圈出输出变量

  s = 进位次数（不是 a+b 的和！）

━━━━━━━━━━━━━━━━━━━━━━━━━━
第16题  当输入 1 1 时，输出为 2？
  手算：1+1=2 < 10 → 不进位 → s=0
  答：F

━━━━━━━━━━━━━━━━━━━━━━━━━━
第17题  两数都不超过 99999（各 5 位），输出可能大于 5？
  5 位数相加，最多进位 5 次
  最大 s=5 → 不可能大于 5
  答：F

━━━━━━━━━━━━━━━━━━━━━━━━━━
第18题  输出 s 永远 ≤ a 的位数 且 ≤ b 的位数？
  找反例：a=5（1 位），b=95（2 位）
    个位 5+5=10   → 进位，s=1
    十位 0+9+1=10 → 进位，s=2
    s=2 > a 的位数 1 → 反例成立
  答：F

━━━━━━━━━━━━━━━━━━━━━━━━━━
第19题  输入 998244353 31415926，输出？
  列竖式 + 逐位进位跟踪表：
    位   x    y    c   x+y+c≥10?   s
    1   3    6    0    否          0
    2   5    2    0    否          0
    3   3    9    0    是          1
    4   4    5    1    是          2
    5   4    1    1    否          2
    6   2    4    0    否          2
    7   8    1    0    否          2
    8   9    3    0    是          3
    9   9    0    1    是          4
  答：s=4

━━━━━━━━━━━━━━━━━━━━━━━━━━
第20题  输入 307506234 692493766，输出？
  同法竖式 + 跟踪表：
    位   x    y    c   x+y+c≥10?   s
    1   4    6    0    是          1
    2   3    6    1    是          2
    3   2    7    1    是          3
    4   6    3    1    是          4
    5   0    9    1    是          5
    6   5    4    1    是          6
    7   7    2    1    是          7
    8   0    9    1    是          8
    9   3    6    1    是          9
  答：s=9
```

**家长检查要点**（孩子草稿必须满足）：
1. **先圈输出变量**：纸上写"`s = 进位次数`"——本大题 5 题全对的前提。
2. **判断题先写反例**：18 题的"反例：a=5, b=95"必须出现在纸上。
3. **输出题有跟踪表**：19、20 题有逐位表格，非心算猜答案。
4. **连续作答**：16–20 在同一页连着写，共用程序理解，不分开重抄。

> 孩子做到这四点，加法进位这类题不会失分。
