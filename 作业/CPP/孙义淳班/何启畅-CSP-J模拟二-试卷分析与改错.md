#### 第8题（错：答 B，正 C）【今日新错】
> 在简单图中，有 n 个顶点的强连通图最少有（ ）条边，最多有（ ）条边
> A. n−1, n　B. n−1, n(n−1)　C. n, n(n−1)　D. n, n(n−1)/2

**推理**：
- **强连通**：任意两顶点互相可达。最少边 = **n** 条——一个环即可（1→2→…→n→1，每个点都能到其他点）。
- 最多边 = **n(n−1)** 条——完全有向图（每对顶点之间两条方向相反的边，共 n(n−1) 条），显然强连通。
- 答 **C**。选 B（n−1, n(n−1)）——把"弱连通树"的 n−1 条边误用于强连通；强连通至少要成环，n 个点成环需 n 条边。

#### 第9题（错：答 B，正 C）【今日新错】
> 以下关于强连通图的说法中，正确的是（ ）
> A. 图中一定有环　B. 每个顶点的度数都大于 0　C. 对于大于 1 个点的强连通图，任意两个顶点之间都有路径相连　D. 每个顶点至少都连有一条边

**推理**：强连通定义 = **任意两点互相可达**。单点图（n=1）无环也强连通 → 排除 A（"一定有环"太绝对）。C 正是定义本身（任意两点有路径，含双向）→ 答 **C**。
选 B/D 的误区："度数大于 0""至少连一条边"——单点图度数 0 也强连通，故 B、D 不成立。

#### 第13题（错：答 B，正 A）【今日新错】
> 正整数 n≥3 称为理想数，若存在 k(1≤k≤n−1) 使 C(n,k−1)、C(n,k)、C(n,k+1) 构成等差数列，则不超过 2026 的理想数个数为（ ）
> A. 43　B. 44　C. 45　D. 46

**推理**：三个组合数成等差数列 ⇔ C(n,k−1) + C(n,k+1) = 2·C(n,k)。利用组合恒等式化简，得经典结论：理想数 n 为完全平方数或二倍完全平方数，≤2026 共 **43** 个 → **A**。
选 B（44）——多算了一个不满足条件的数。此题偏难，属组合数性质+枚举，掌握"等差数列→组合恒等式化简→枚举验证"套路即可。

#### 第14题（错：答 D，正 C）【⚠️ 持续错，两次皆错——务必根治】
> 已知一棵二叉树有 2026 个结点，则其中至多有（ ）个结点有 2 个子结点
> A. 1010　B. 1011　C. 1012　D. 1013

**推理**：设度 0/1/2 的结点数为 n0、n1、n2。
- 结点总数：n0 + n1 + n2 = 2026
- 边数：n0·0 + n1·1 + n2·2 = 边数 = 结点数 − 1 = 2025
- 二叉树性质：**n0 = n2 + 1**（叶结点 = 2 度结点 + 1）

代入：n2+1 + n1 + n2 = 2026 → **2·n2 + n1 = 2025**。要 n2 最大，n1 取最小。2025 是奇数，2·n2 是偶数，n1 必须为奇数 → n1 最小取 **1**。n2 = (2025−1)/2 = **1012**。

答 **C**。选 D（1013）——可能误用 `(2026−2)/2` 或数错。**规范做法：列"结点数/边数/叶结点性质"三方程，n1 取最小可行值**。此套路必背，下次见"二叉树度/结点数"先列三式。

### 阅读·第1题 冒泡排序（今日错 18、20）

**源码逐行注释**（学生照此格式读程序）：
```cpp
// check(n, a)：对数组 a 做一趟"冒泡扫描"，返回本趟是否发生过交换
bool check(int n, int a[])
{
    bool found = false;                  // found：本趟是否发生交换，初值 false
    for (int i = 0; i + 1 < n; ++i) {    // 从左往右扫到倒数第 2 个元素（i+1<n 保证 a[i+1] 存在）
        if (a[i] > a[i+1]) {             // 若左边元素 > 右边元素（逆序对）
            found = true;                //   标记：本趟交换过
            auto temp = a[i];            //   交换 a[i] 与 a[i+1]（大数右沉、小数左浮）
            a[i] = a[i+1];
            a[i+1] = temp;
        }
    }
    return found;                        // 本趟结束，返回"是否交换过"
}

// solve(n, a)：反复整趟扫描，直到某趟无交换（数组已有序）——即冒泡排序
void solve(int n, int a[])
{
    while (check(n, a))                  // 只要上一趟还有交换，就再来一趟
        ;                                // 循环体是空语句（分号），什么都不做
}
```

**先懂程序在干什么**：`check` 一趟从左到右扫描，凡 `a[i] > a[i+1]` 就交换，记 `found=true`；`solve` 反复整趟扫描直到某趟无交换。这就是**冒泡排序**，结束**升序**。

#### 第18题（错：答 T，正 F）【今日新错】
> 当 n=5，a = [1, 2, 3, 4, 5] 时，while 循环只运行一次（ ）

**推理**：a 已升序，第一趟 `check(5, a)` 扫描全程**无任何交换**，`found` 保持 false，check 返回 false。`while (check(n, a))` 条件第一次判断即为 false → **循环体一次都不执行**（0 次），不是 1 次。答 **F**。

**误区**：把"while 循环只运行一次"理解为"check 被调用一次"——while 的判断本身会调用 check 一次（得到 false），但**循环体**运行 0 次。判断题考的是"循环体执行次数"。

#### 第20题（错：答 T，正 F）【⚠️ 持续错，两次皆错——务必根治】
> 当 solve 结束后，a 数组以降序排列（ ）

**推理**：冒泡排序把相邻逆序对交换，大数**右沉**，结束时时**升序**，不是降序。答 **F**。
**规范答法**：凡冒泡必问"大数往哪走"——`a[i] > a[i+1]` 就交换，大的永远向右，结果必升序。方向看 `>` 还是 `<` 一句定。

**阅读做法**：冒泡题先锁定"相邻交换 + 无交换即停"＝升序；while 次数题数"循环体执行了几次"，不是"函数被调了几次"。

### 阅读·第2题 二进制计数（今日错 25、26、29）

**源码逐行注释**（学生照此格式读程序）：
```cpp
// move(b, n)：把 b 当作 n 位二进制数（b[0] 是最低位），做一次"加 1"
bool move(int b[], int n)
{
    for (int i = 0; i < n; ++i) {        // 从最低位 b[0] 往高位扫
        if (b[i] == 1) { b[i] = 0; }     // 当前位是 1 → 置 0（相当于进位，继续看下一位）
        else { b[i] = 1; return true; }  // 当前位是 0 → 置 1，加 1 完成
    }
    return false;                        // 所有位都是 1 → 全部变 0，溢出归零
}

// print(n)：从全 0 开始，每次打印当前 n 位二进制，再 move 加 1，直到溢出
void print(int n)
{
    int b[n];
    for (int i = 0; i < n; ++i) b[i] = 0;   // 初始化全 0
    do {                                    // do-while：先打印一次，保证至少输出一行
        for (int i = 0; i < n; ++i) std::cout << b[i];  // 逐位输出 b[0]..b[n-1]
        std::cout << "\n";                  // 换行
    } while (move(b, n));                   // move 加 1；返回 false（溢出）时结束
}

// count(n)：数一数一共能加几次 1（即状态总数）
int count(int n)
{
    int b[100];
    for (int i = 0; i < n; ++i) b[i] = 0;   // 初始化全 0
    int c = 0;
    do { c++; } while (move(b, n));         // 每 move 成功一次 c 加 1
    return c;                               // 返回 2ⁿ
}
```

**先懂程序在干什么**：`move` 把 b 当 n 位二进制数做"加 1"：从最低位起逢 1 变 0（进位），遇第一个 0 变 1 返回 true；全 1 则溢出归零。`print(n)` 打印 0..2ⁿ−1 的 n 位二进制；`count(n)` 状态总数 = 2ⁿ。

#### 第25题（错：答 F，正 T）【今日新错】
> print 输出的 0 与 1 必然一样多（ ）

**推理**：print(n) 输出 0 到 2ⁿ−1 的**全部** n 位二进制数，共 2ⁿ 行。n 位二进制数中，**每一位**上 0 和 1 各出现 2ⁿ⁻¹ 次。n 位累加：0 的总数 = 1 的总数 = n·2ⁿ⁻¹。**必然一样多** → **T**。
选 F 的误区：只看了小样本（前几行 0 多），没想"全部 2ⁿ 个数"的对称性。

#### 第26题（错：答 T，正 F）【今日新错】
> print(6) 输出的第 5 行第 4 列（从左往右数）的字符为 0（ ）

**推理**：print(6) 输出 0..63 的 6 位二进制。第 5 行 = 数字 4 = `000100`。从左数第 4 个字符：位置1=0, 2=0, 3=0, 4=**1**, 5=0, 6=0。第 4 个字符 = **1**，非 0 → **F**。
选 T 是把"第 4 列"看错成第 3 列，或把 000100 数错。**规范答法：先写出行对应的数（第5行→数字4→000100），再从左一位位数**。

#### 第29题（错：答 C，正 B）【⚠️ 持续错，两次皆错——务必根治】
> print(n) 与 count(n) 的时间复杂度为（ ）
> A. Θ(2ⁿ), Θ(2ⁿ)　B. Θ(n·2ⁿ), Θ(2ⁿ)　C. Θ(n·2ⁿ), Θ(n·2ⁿ)　D. Θ(4ⁿ), Θ(2ⁿ)

**推理**：
- `print(n)`：共打印 2ⁿ 行，每行 n 个字符，输出总量 = **n·2ⁿ** → Θ(n·2ⁿ)。
- `count(n)`：循环 2ⁿ 次，每次只做 `c++`。move 每趟最长扫 n 位，但**均摊**后总工作量 = 所有位翻转次数之和 = 2ⁿ + 2ⁿ⁻¹ + … + 2 ≈ 2ⁿ⁺¹，仍是 Θ(2ⁿ)。（计数器从 0 数到 2ⁿ 的总操作量是 O(2ⁿ)，经典均摊结论。）

**逐行模拟证明**（n=3，数 move 一共扫了多少位）：
```
状态:  000 → 001 → 010 → 011 → 100 → 101 → 110 → 111 → 000
move扫:   1      2      1     3     1     2     1     (溢出时3)
         └ b[0]每次加1都动；b[1]每2次动1次；b[2]每4次动1次
总扫描 = 8×1(最低位) + 4×1(次低位) + 2×1(最高位) + 溢出3 = 17 ≈ 2×8 = Θ(8)
```
即 n 位计数器从 0 数到 2ⁿ 的总工作量 = 2ⁿ + 2ⁿ⁻¹ + … + 1 ≈ 2ⁿ⁺¹，**Θ(2ⁿ)**，不是 n·2ⁿ。答 **B**。

**误区**：把"每次 move 可能 O(n)"直接乘上 2ⁿ 得 O(n·2ⁿ)——错。要算**总工作量**：所有 move 扫描长度加起来 = Σ 进位位数 = 2ⁿ⁺¹−2，仍是 Θ(2ⁿ)。

**阅读做法**：二进制题先认出"从最低位逢 1 置 0 继续、遇 0 置 1 即停"＝加 1（与竖式加法同构）→ 枚举 0..2ⁿ−1。复杂度题数"总工作量"（均摊），非每次×次数。

### 阅读·第3题 公共子序列（今日错 33、34）

**源码逐行注释**（学生照此格式读程序）：
```cpp
const int mod = 1'000'000'007;           // mod：取模常数，防溢出
bool filled[maxn][maxn];                 // filled[i][j]：(i,j) 是否已算过（记忆化标记）
int mem[maxn][maxn];                     // mem[i][j]：f(i,j) 的结果缓存

// solve(i, j, a, b)：返回 a 前 i 个与 b 前 j 个的公共子序列个数（含空序列）
int solve(int i, int j, int a[], int b[])
{
    if (i == 0 || j == 0) return 1;      // 边界：有一边为空，只有空序列这 1 个
    if (filled[i][j]) return mem[i][j];  // 算过就直接返回缓存（记忆化）
    filled[i][j] = true;                 // 标记本格开始计算
    int sum = (solve(i-1, j, a, b) + solve(i, j-1, a, b)) % mod;  // 容斥：先加两半，再处理重复
    if (a[i] == b[j]) {                  // 若两序列末尾元素相等
        return mem[i][j] = sum;          //   f = f(i-1,j) + f(i,j-1)（重复项与新增项抵消）
    } else {                             // 若不相等
        return mem[i][j] = (sum - solve(i-1, j-1, a, b)) % mod;  //   f 再减去 f(i-1,j-1) 排除重复
    }
}
```

**先懂程序在干什么**：设 f(i,j) = a 前 i 个与 b 前 j 个的**公共子序列个数**（空序列算 1）。边界 i=0 或 j=0 → 1。容斥递推 f(i,j) = f(i−1,j) + f(i,j−1) − f(i−1,j−1)，a[i]==b[j] 时抵消重复项。`filled`/`mem` 记忆化。**功能 = 公共子序列计数**。

#### 第33题（错：答 T，正 F）【⚠️ 持续错，两次皆错——务必根治】
> solve(n, n, a, a) 返回 2ⁿ（ ）

**推理**：若 a 中元素**互不相同**，a 与自身公共子序列就是 a 的全部子序列，共 2ⁿ 个。但题目没说明元素互异！若 a 有重复元素，程序按"位置组合"计数，结果会变。

**逐行模拟找反例**（a = [1,1]，b = a，n=2）：
```
solve(2,2): 先算 solve(1,2) 与 solve(2,1)
├ solve(1,2): 算 solve(0,2)=1 与 solve(1,1)
│  └ solve(1,1): a1=1==b1=1 → f(0,1)+f(1,0)=1+1=2  ← mem[1][1]=2
│  a1=1==b2=1 → f(1,2)=f(0,2)+f(1,1)=1+2=3  ← mem[1][2]=3
├ solve(2,1): a2=1==b1=1 → f(2,1)=f(1,1)+f(2,0)=2+1=3  ← mem[2][1]=3
a2=1==b2=1 → f(2,2)=f(1,2)+f(2,1)=3+3=6  ← mem[2][2]=6
```
返回 **6 ≠ 4 = 2²**。反例成立，命题不真 → **F**。

**规范答法**：判断题出现"必然 2ⁿ""一定…"字样，先问"条件够吗"——没说明元素互异就是陷阱。**找反例一击毙命**。

#### 第34题（错：答 F，正 T）【⚠️ 持续错，两次皆错——务必根治】
> 函数 solve 的返回值可能小于 0（ ）

**推理**：`(sum - solve(i-1,j-1,a,b)) % mod`——C++ 中**负数取模结果仍为负数**。`sum` 是两项取模后相加再取模，可能比 `solve(i-1,j-1) % mod` 小，相减为负、取模后仍负。所以返回值**可以小于 0**。

**模拟验证**：若 mod=10，假设 `solve(i-1,j)%mod + solve(i,j-1)%mod = 3`，而 `solve(i-1,j-1)%mod = 7`，则 `(3−7)%10 = −4 < 0`。合法。答 **T**。

> 这是 C++ 负数取模的坑——`%` 结果符号与被除数一致，与数学上"模运算归到 0..mod−1"不同。

**阅读做法**：判断题先找反例（33）；C++ 取模符号题想"负号跟被除数走"（34）。公共子序列计数与"最长公共子序列"区分：长度题边界 0、递推 max；计数题边界 1、递推加减。

### 完善·第1题 套餐限价（今日全对）

**源码逐行注释**（38–42 全对，此处作示范）：
```cpp
long long S[MAXN];                       // S：B 的前缀和，S[k]=B[0]+…+B[k-1]
long long solve(int N, int M, int L, int A[], int B[])
{
    std::sort(A, A + __(1)__);           // (1) = N：A 升序排序，区间 [A, A+N)
    std::sort(B, B + M);                 // B 升序排序
    S[0] = 0;                            // 前缀和首项
    for (int i = 0; i < M; ++i) S[i+1] = S[i] + B[i];   // 算 B 前缀和
    long long j = __(2)__;               // (2) = M：分界指针从最右端开始
    long long sum = 0;                   // sum：答案
    for (int i = 0; i < N; ++i) {        // 枚举每个主食 A[i]
        while (__(3)__ && A[i] + B[j-1] > L) { j--; }   // (3) = j > 0：向左收缩，直到 A[i]+B[j-1] ≤ L

    }
    return sum;                          // 返回总花费
}
```
