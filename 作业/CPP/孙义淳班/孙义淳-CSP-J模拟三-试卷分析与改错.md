### 3.1 单选·基础

- **第12题**（答 A，正 C）输入 n 个不等数，输出第二小的数，最坏比较次数。
  ```cpp
  if (a[1] < a[2]) { min1=a[1]; min2=a[2]; }
  else { min1=a[2]; min2=a[1]; }
  for(int i=3; i<=n; i++)
      if (a[i] < min2)
          if (a[i] < min1) { min2=min1; min1=a[i]; }
          else { min2=a[i]; }
  ```
  最坏情况：每次 `a[i] < min2` 都成立（每步都进内层 if），且每次 `a[i] < min1` 也成立（一直更新最小值）。此时每步 2 次比较，共 `2(n−2) + 1`（初始 1 次）= `2n−3`。正 **C**。
  选 A（2n−1）是把"先找最小再找第二小"的朴素法算成 2n−1，但本代码每次比较后直接更新两变量，无需第二轮扫描，故为 2n−3。

**单选做法**：计数题（比较次数/方案数）先看清**每次循环做几次操作**，再乘循环次数，勿套通用公式。此题关键——比较发生在"两分支"，最坏是每步都进内层，故每步 2 次。

### 3.2 阅读·第1题 约数求和（16–21）

程序：f(n) 返回 n 的**真约数和**（含 1，不含 n 本身）。i 从 2 到 √n，找到约数 i 则加 i 和 n/i；若 i²=n 再加 i。

- **第18题**（未答，正 T）存在两个不同的数 m、n，使 f(m) = f(n)。例：f(5)=1+5=6（质数），f(6)=1+2+3=6，f(5)=f(6)=6。存在 → **T**。未答可惜，随手举一反例即得。
- **第21题**（答 A，正 B）f(1024) 返回值。1024=2¹⁰，i 从 2 到 31（32²=1024 不 < 1024）：
  ```
  i   i²   1024%i?   s
  2   4    0         1+2+512=515
  4   16   0         515+4+256=775
  8   64   0         775+8+128=911
  16  256  0         911+16+64=991
  32  1024 退出（i²≠<n）
  i²==n ✓ → s=991+32=1023
  ```
  → **B**。选 A（512）只算了 2⁹ 本身，没把各约数累加全。

**阅读做法①：逐行注释——先翻译每行代码**
```
i64 s = 1;          // s：约数和，初始 1（1 总是约数）
i64 i = 2;          // i：从 2 开始试除
while (i * i < n) { // 只试到 √n（i²>n 则不可能再有更大约数）
    if (n % i == 0) {     // i 是 n 的约数
        s += i;           // 加 i
        s += n / i;       // 加另一约数 n/i
    }
    ++i;
}
if (i * i == n) s += i;   // i²=n（完全平方数），加 i 勿重复
```
逐行注释做完，每行干什么都清楚了——"枚举√n 以内约数对"这一功能自然浮现。

### 3.3 阅读·第2题 三重循环（22–28）

程序：对每对 (j,i) 求 a[j..i] 之和，累加到 ret。

**源码逐行注释**（学生照此格式读程序）：
```cpp
int solve(int n, int a[])
{
    int ret = 0;                       // ret：累加器，最终答案
    for (int i = 0; i < n; ++i) {      // i：子数组右端点（0 到 n-1）
        for (int j = 0; j < i; ++j) {  // j：子数组左端点（0 到 i-1，保证非空）
            int sum = 0;               // sum：这一段 a[j..i] 的和
            for (int k = j; k <= i; ++k) {   // k：从左端点走到右端点
                sum += a[k];           //    逐项累加进 sum
            }
            ret += sum;                // 每段和都加进答案
        }
    }
    return ret;                        // 返回所有子数组和的总和
}
```
逐行注释完成，功能自然浮现：**枚举所有非空子数组、求各段和再累加**。数循环层数 → 三层 for → Θ(n³)（第27题）。

- **第25题**（答 A，正 D）n=10，a 全 1 时的返回值。$ret = Σ_{i=1}^{n−1} Σ_{j=0}^{i−1} Σ_{k=j}^{i} a[k]$（a 全 1 时 = 子数组长度）。
  对固定 i，j=0..i−1，子数组长度 i−j+1。$求和 = Σ_{j=0}^{i−1} (i−j+1) = Σ_{t=1}^{i} (t+1) = i(i+1)/2 + i = i(i+3)/2$。
  i=1..9 求和：$Σ i(i+3)/2 = (4+10+18+28+40+54+70+88+108)/2 = 420/2$ = **210** → **D**。
  选 A（10）只数了 i 的个数，未理清三重循环的计算量。
- **第27题**（答 A，正 D）时间复杂度：三重循环嵌套，每层 O(n)，总体 **Θ(n³)** → **D**。选 A（Θ(n)）未数循环层数。

**阅读做法②：找破局点 + 手算模拟**

**找破局点**——回看逐行注释，问"哪几行是命门？删掉哪行程序就变了？"

| 程序 | 逐行读完后浮现的关键行 | 锁定功能 |
|------|------|------|
| 约数求和 | `i*i<n` + `n%i==0` 加 i 与 n/i + `i*i==n` 补 | 枚举√n 以内约数对，求真约数和 |
| 三重循环 | 三层 for + 内层 `sum+=a[k]` + 外层 `ret+=sum` | 所有子数组之和的累加 |
| 二进制计数 | `c[i]=c[i/2]+i%2` 递推 + `sum+=c[i]` | 数 0..n-1 的二进制 1 总数 |

**手算模拟**——拿小数据逐行执行，写下来不心算。三重循环题（25）：先固定 i，数清内层 j 取几个、每个子数组多长，再对 i 求和；第27题复杂度同法——数循环层数。

### 3.4 阅读·第3题 二进制计数（29–35）

**源码逐行注释**（学生照此格式读程序）：
```cpp
using i64 = long long;

// solve1：统计 0..n-1 全体二进制数里"1"的总个数
i64 solve1(i64 n)
{
    std::vector<i64> c(n);             // c[i]：数字 i 的二进制里"1"的个数
    c[0] = 0;                          // 0 的二进制没有 1
    i64 sum = 0;                       // sum：累加 0..n-1 各自的 1 个数
    for (i64 i = 1; i < n; ++i)
    {
        c[i] = c[i / 2] + (i % 2);     // 递推：i 的 1 个数 = (i/2 的 1 个数) + (最低位是 1 吗)
        sum += c[i];                   // 累加到总答案
    }
    return sum;
}

// solve2：返回 {0..n 全体二进制 1 的总数, n 的二进制里 1 的个数}
std::pair<i64,i64> solve2(i64 n)
{
    if (n == 0)
        return {0, 0};                 // 边界：0 的 1 个数为 0
    auto r = n % 2;                    // r：n 的最低位
    auto q = n / 2;                    // q：n 去掉最低位后的高一半
    auto [s, c] = solve2(q);           // 递归：先算 q 的 {总数, 1 个数}
    if (r == 1)
        return {s*2 + q + c, c + 1};   // 最低位为 1：总数翻倍 + 高位贡献 q+c，1 个数 +1
    else
        return {s*2 + q, c};           // 最低位为 0：总数翻倍 + 高位贡献 q，1 个数不变
}
```
逐行注释后：solve1 是**线性递推**（O(n)），solve2 是**二分递归**（每次 n/2，O(log n)）——第34题答案来源。c[i]=c[i/2]+i%2 加的是"最低位是否为 1"，故数的是 **1** 非 0（第32题答案来源）。

- **第32题**（答 A，正 B）solve1 计算的是"0 到 n−1 全体二进制数 **1 出现的数量**" → **B**。选 A（零的数量）——c[i]=c[i/2]+i%2 每次加的是 i%2（0 或 1），只在奇数时加 1，故数的是 1 不是 0。
- **第33题**（答 A，正 D）solve2 第二返回值 c 是"参数 n 的二进制表示下 **1 的数量**" → **D**。选 A（二进制长度）——递归拆 n%2 与 n/2，逢奇数 c+1，数的是 1 个数，非长度。
- **第34题**（答 A，正 B）复杂度：solve1 循环 n 次 → Θ(n)；solve2 每次 n/2 → Θ(log n)。选 A（两者都 Θ(n)）——没发现 solve2 是指数缩减。
- **第35题**（答 A，正 B）solve1(4096) = 0..4095 的二进制 1 总数。4096=2¹²，0..2¹²−1 共 4096 个数，每位数上 1 出现 2¹¹ 次，共 12 位 → 12×2¹¹ = 4096×6 → **B**。选 A（4096×5）——少算了一位。

**阅读做法③：按题型答题 + 坑位清单**

**按题型答题**：
- **判断题**：找反例。18 题"存在 m≠n 使 f(m)=f(n)"——找 f(5)=f(6)=6 即正例 → T。**先找反例，找不出且直觉成立才答 T**。
- **输出题**：手算。21 题 f(1024) 画表推。
- **复杂度题**：数循环层数。27 题三层 for → Θ(n³)；34 题 solve1 一层 for → Θ(n)、solve2 递归 n/2 → Θ(log n)。
- **功能题**：排除干扰项。32 题 c[i]=c[i/2]+i%2：加的是"i%2"（0 或 1），不是"1−i%2" → 数的是 1 非 0。

**坑位清单**：

| 坑 | 本卷例子 | 防坑口诀 |

### 3.5 完善·第1题 石头剪刀布（36–40）

DP 题：对手出拳序列已知，你每次出 R/S/P 之一，从未输过（非赢即平），相邻两次不同。R/S/P 分别记"当前以该手势收尾时最大赢局数"。

**补全后完整源码 + 逐行注释**（学生照此理解填空思路）：
```cpp
#include<iostream>
int score(int a,int b){
    if(a==b) return 0;                 // (1) 平局：a==b → 0 分
    else if(a=='R' and b=='S')return 1;   // 石头赢剪刀 → 1
    else if(a=='S' and b=='P')return 1;   // (2) 剪刀赢布 → 1
    else if(a=='P' and b=='R')return 1;   // 布赢石头 → 1
    else return -10000000;             // 输：不合法（条件保证不输），极小值排除
}

int main(){
    int R=0,S=0,P=0;                   // (3) 初始三种手势的赢局数全 0
    int n;
    std::cin>>n;
    while(n-->0){
        char c;
        std::cin>>c;                   // 对手本轮出拳
        int newR = std::max(S,P)+score('R',c);  // (4) 本轮出 R：上轮不能 R，取 max(S,P)
        int newS = std::max(R,P)+score('S',c);  // (5) 出 S：取 max(R,P)
        int newP = std::max(R,S)+score('P',c);  // (6) 出 P：取 max(R,S)
        R=newR;                        // 滚动更新
        S=newS;
        P=newP;
    }
    std::cout<< std::max(std::max(R,S),P);  // (7) 输出三种手势中最大赢局数
}
```

- **第36题**（答 A，正 D）score 函数中 (1) 处：平局返回 0。平局时 a==b → **D**。选 A（a!=b）——语义反了，a!=b 时胜负未分，不应返回 0。
- **第40题**（答 A，正 B）(7) 处输出：三种手势最大赢局数 → max(R,S,P) → **B**。选 A（min）——求最大非最小。

**补全做法①：先整体理解 + 变量角色表**

**先整体理解**：读完题干先自问"程序要算什么"——石头剪刀布是**DP**：每轮由上一轮三种手势的赢局数推新值，初始 0，逐轮更新，最后输出最大值。

**变量角色表**——填空前先填表，填不出不动笔：

| 题组 | 变量 | 含义 |
|------|------|------|
| 石头剪刀布 | R/S/P | 某轮出该手势时已累计的最大赢局数 |
| 石头剪刀布 | score(a,b) | 若 a 赢 b 返回 1，平返回 0，输返回 -10000000 |
| 石头剪刀布 | newR/newS/newP | 新轮三种手势的累计值 |

填表后再看空：(1) 平局返回 0 → a==b；(7) 输出 → 三手势取最大。变量角色不清，填空必错。

### 3.6 完善·第2题 火柴三角形（41–45）

记忆化搜索：枚举每根火柴分配三边，海边伦公式 16s² 求最大面积。

**补全后完整源码 + 逐行注释**（学生照此理解填空思路）：
```cpp
#include<iostream>
using i64 = long long;
int n;
int a[40];
bool mem[40][40*40][40*40];          // mem[x][y][z]：三边为 x,y,z 是否已算过
i64 value[40][40*40][40*40];         // value[x][y][z]：对应的最大面积（16s²）

i64 solve(int i, int x, int y, int z) {
    if (i < n) {                     // 还没分完所有火柴
        if (mem[x][y][z] > 0) return value[x][y][z];  // (1)(2) 记忆化：算过直接返回
        auto s1 = solve(i+1, x + a[i], y, z);   // 第 i 根分给边 x
        auto s2 = solve(i+1, x, y + a[i], z);   // 分给边 y
        auto s3 = solve(i+1, x, y, z + a[i]);   // 分给边 z
        mem[x][y][z] = true;         // (3) 标记已算
        return value[x][y][z] = std::max(std::max(s1, s2), s3);  // (4)(5) 取三种分配的最大
    }
    else {                           // 全部火柴已分完
        if (x + y <= z || x + z <= y || y + z <= x) return 0;  // (6) 不能成三角形 → 0
        i64 p = x + y + z;           // (7) p：周长 = 半周长×2
        return p * (p - 2*x) * (p - 2*y) * (p - 2*z);  // (8) 海伦公式 16s²
    }
}
```

- **第44题**（答 A，正 B）(7) 处 p = x+y+z（半周长×2）。海伦公式 16s² = 2p·(2p−2x)(2p−2y)(2p−2z) 中 p 为半周长。程序中 (8) 用 p*(p-2x)*(p-2y)*(p-2z)，故 p 应为 x+y+z（即半周长×2），非 xyz → **B**。选 A（x*y*z）——误把周长当乘积。

**补全做法②：填空技巧 + 代入验证 + 捡分策略**

**填空技巧**：
- **入口空先拿**：main 里的第一次调用 → 一定是起点。火柴题 `solve(0,0,0,0)` 从 0 开始。
- **边界与终止**：递归到哪停 → 火柴题 i==n 时算面积。
- **分情况**：石头剪刀布每轮三种选择各自更新；火柴题每根火柴分配三边，三种选择。
- **公式对照**：海伦公式要背准——半周长 p 与 16s² 的关系，(7) 处缺的是"两倍半周长"，非乘积。

**代入验证**：填完取小样例手跑，值突变即某空错。

**捡分策略**：
- 先填入口空、边界空、标记空——这些不看算法也能推。
- 蒙也要填，每空 3 分，不填 0 分。
- 本卷 36、40、44 只要肯代入选项对比，至少能排除一半。

### 3.7 附加·括号递归（46–52）【S 组提高题】

**源码逐行注释**（学生照此理解递归解析）：
```cpp
int exp();                            // 前向声明：exp 和 term 互相调用

// term：读一对括号"()"，中间夹一个 exp
int term()
{
    char begin, end;
    std::cin >> begin;                // 读左括号 '('
    int t = exp();                    // 括号里的内容（递归）
    std::cin >> end;                  // 读右括号 ')'
    if (t == 0)
        return 1;                     // 空括号 () → 值为 1
    else
        return t * 2;                 // 非空：值 = 内层值 × 2
}

// exp：读若干对"()"并列，值相加；读到非 '(' 返回 0
int exp()
{
    if (std::cin.peek() == '(')       // 下一个字符是 '('
    {
        return term() + exp();        // 读一对 () + 继续往后读
    }
    else
    {
        return 0;                     // 没有 '(' 了 → 0（作为"空表达式"）
    }
}

int main()
{
    std::cout << exp() << "\n";       // 从头开始解析整串括号
}
```
