## 三、逐题改错

### 单选·基础

- **第1题** 源码→机器代码步骤，问的是源代码步骤，孩子没看清楚以为是运行的。正 **A**（预处理、编译、链接）。误选 B（编辑、编译、运行）——"编辑"是写文本，"运行"是执行，均非转换步骤。
- **第6题** 二叉树后序。前序 `F,C,A,D,B,E`，中序 `A,C,B,D,F,E`。根 F；左子树根 C，中序见 A 在 C 左、B,D 在 C 右；D 左子 B。后序：`A,B,D,C,E,F`。正 **B**。误选 A（`A,B,C,D,E,F`）——未好好画图，然后按"左-右-根"顺序。
- **第8题** 后缀表达式 `3 4 * 2 5 + - 6 *`。栈式求值：`3 4 *`=12；`2 5 +`=7；`12 7 -`=5；`5 6 *`=30。正 **B**。误选 C（42）——运算次序错。
- **第9题** 6 本不同书分 3 人每人至少 1 本。容斥：`3⁶ − 3·2⁶ + 3 = 729 − 192 + 3 = 540`。正 **A**。误选 D（120）——应"任意分 729 − 有人空手 192 + 两人空手 3"。
- **第13题** 哈夫曼编码。频率 40/30/20/10：`10+20=30`，`30+30=60`，`40+60=100`。A（40%）在根的孩子层，编码长度 **1**。正 **A**。误选 B（2）。

### 阅读·加法进位（16–20）——程序统计两数相加的进位次数，非求和

- **第16题** 输入 `1 1`：`1+1=2 < 10` 不进位，`s=0`。正 **F**。误答 T。
- **第17题** 两数 ≤ 99999（各 5 位），进位最多 5 次，不可能大于 5。正 **F**。误答 T。
- **第18题** `s` 可大于 `a` 的位数。例：`a=5`（1 位）、`b=95`（2 位）——个位 5+5=10 进位，十位 0+9+1=10 再进位，`s=2 > 1`。正 **F**。误答 T。
- **第19题** 输入 `998244353 31415926`：逐位看进位 `3+6`、`5+2` 不进；`3+9`、`4+5+1`、`9+3`、`9+0+1` 共进 4 次。正 **B**。误选 D（966828427）——这是**两数和**，不是进位次数。
- **第20题** 输入 `307506234 692493766`：从个位起 `4+6`、`3+6+1`、… 每位都进 1，共 **9** 次。正 **D**。误选 A（384987532）——又是选了和。
- 教训：输出变量是 `s`（进位计数），19/20 题两次选了"和"选项——没读到底，看到 `a+b` 就想求和。

### 阅读·删字符（21–26）

- **第21题** `size > 0` 改 `size >= 0`：`size=0` 时取 `s[size-1]` 即 `s[-1]`，越界，行为改变。正 **F**。误答 T。
- **第23题** 循环 10 次、`d > 10` 必崩？否。若字符满足 `top < c` 则 `d` 被消耗（如 11 个都删，`d` 剩 1，`size=1` 不崩）；只有全部不满足时才把 `size` 减负越界。"必崩"过强。正 **F**。误答 T。
- **第25题** 复杂度。每字符入栈一次、出栈至多一次，总体 **Θ(n)**。正 **A**。误选 D（Θ(n+d)）——`d` 是固定参数，不随 `n` 增长，不算规模。
- 21、23 题错在边界与"是否一定"的判断，需用反例思维。

### 阅读·dfs/fib（30–33）

- **第30题** `dfs` 每层两个分支、枚举到第 `n` 层，共 `2ⁿ` 个节点，Θ(**2ⁿ**) 而非 Θ(n²)。正 **F**。误答 T。
- **第31题** `dfs` 用递归枚举全部二进制序列并筛选，思想是**枚举**（回溯）。正 **C**。误选 A（迭代）。
- **第32题** 输入 4：`dfs(0,4)` = 不含连续 1 的长度 4 序列数 = 8（0000/0001/0010/0100/0101/1000/1001/1010）；`fib(4)=8`。输出 `8 8`。正 **C**。误选 A（7 8）——`dfs` 数错。
- **第33题** `dfs` 统计**不含连续 1** 的二进制序列数（`choose[i]&&choose[i+1]` 即连续 1 则弃）。正 **B**。误选 D（所有二进制序列）——没注意筛选条件。

### 完善·有序对（38–39）

程序统计"去重后的不同值对 (ai,aj)、i<j"的个数。填空：(1)=`num`，(2)=`a[i]`，(3)=`c[a[i]]`，(4)=`!present[a[i]]`，(5)=`num++`。

- **第38题 (4)**：`if ( !present[a[i]] ) { present[a[i]]=true; num++; }`——仅首次出现时记录。正 **D**。误选 A（`present[a[i]]`）——条件写反：已出现过时不该重复计数。
- **第39题 (5)**：新值出现，不同值个数 `num++`。正 **D**。误选 B（`num += a[i]`）——`num` 是**个数**（每次 +1），不是累加值本身。
- 根因：`num`（不同值计数）、`present`（是否出现过）两变量角色不清。

### 完善·骨牌（40–45）

回溯枚举骨牌摆放，最大化"未覆盖数字的异或和"。填空：(1)=`solve(0,0,0)`，(2)=`solve(x+1,0,sum)`，(3)=`x==n`，(4)=`solve(x,y+1,sum^a[x][y])`，(5)=`solve(x,y+1,sum)`，(6)=`solve(x,y+1,sum)`。

- **第41题 (2)**：`y==m` 到列尾，换到下一行：`solve(x+1, 0, sum)`。正 **A**。误选 B（`solve(x+1,y,sum)`）——`y` 未归零，下一行从错误列起。
- **第43题 (4)**：当前格不盖骨牌，数字计入异或，右移：`solve(x, y+1, sum ^ a[x][y])`。正 **A**。误选 B（`solve(x+1,y,…)`）——方向错，应右移非下移。
- **第44题 (5)**：竖骨牌盖 (x,y) 与 (x,y+1)，两格数字**都不**计入：`solve(x, y+1, sum)`。正 **C**。误选 A（`sum ^ a[x][y]`）——被覆盖的数字不应参与异或。
- **第45题 (6)**：横骨牌同理，盖 (x,y) 与 (x+1,y)，`solve(x, y+1, sum)`。正 **C**。误选 A——同上。
- 根因：递归方向（右移/换行）与"被覆盖格不进异或"两个关键点没理清。

### 附加·flat_map（49–50）【S 组提高题，J 组不计】

- **第49题** `get` 二分查找，最坏 **O(log n)**。正 **B**。误选 D（O(n log n)）——get 是单层二分，无嵌套循环。
- **第50题** `put` 从尾部搬移比 key 大的元素再插入。标准答案 **A（O(1)）**；但按代码实现，搬移需移动至多 `size` 个元素，最坏实为 **O(n)（C）**，此处答案疑有误。选 C 从代码逻辑看反为正确认知，可按标准答案 A 记，同时明白 put 有搬移开销。

### 附加·次大值（54–57）【S 组提高题，J 组不计】

排列所有连续子区间次大值之和，单调栈（从大到小删点）解法。填空：(1)=`q[p[i]]=i`，(2)(3)(4)=`p[i],prev_num,next_num`，(5)=`(q[prev_num]-q[prev_prev_num])`，(6)=`(q[next_next_num]-q[next_num])`，(7)(8)=`prev[next_num],next[prev_num]`。

- **第54题 (2)(3)(4)**：`num` 取当前值 `p[i]`；`prev[num]=prev_num`（左邻居）、`next[num]=next_num`（右邻居）。正 **A**。误选 B（`q[i],next_num,prev_num`）——`num` 应是值 `p[i]` 而非位置 `q[i]`，且 prev/next 赋值颠倒。
- **第55题 (5)**：num 作次大值的左边区间宽度 `q[prev_num] − q[prev_prev_num]`。正 **A**。误选 C（`q[next_num] - q[prev_prev_num]`）——左右端点混用。
- **第56题 (6)**：右边区间宽度 `q[next_next_num] − q[next_num]`。正 **D**。误选 C（`q[next_num]-q[prev_prev_num]`）——同上。
- **第57题 (7)(8)**：删除 num 后，把左右邻居接上：`prev[next_num]=prev_num; next[prev_num]=next_num`。正 **B**。误选 A（`prev[prev_num],next[next_num]`）——该更新的是 **num 的邻居**的指针，不是 num 自己的。
- 根因：对单调栈"删点、接链"模型不熟，四个数组（p 排列、q 位置、prev/next 双向链表）关系未建立。

## 四、程序阅读做法（必读）

阅读程序题的核心：**读懂程序在算什么**，再回答"判断题 / 输出 / 复杂度 / 功能"四类问题。

### 1. 三步走：读题 → 读程序 → 验证

1. **先读题干**：程序处理什么输入、输出什么（加法进位输出 `s`，删字符输出字符串）。
2. **读 main**：看输入变量、调用结构、输出变量——**务必认清输出的是哪个变量**。
   - 19/20 题栽在"输出是进位次数 s，不是和"——认错输出变量，全盘皆输，就是扫了一眼题目，没仔细看。
3. **猜功能**：把程序当黑盒，先给个大致功能判断，再细读验证。

### 2. 手算模拟（对付"输出题"）

对给定输入，**逐行推演**，像电脑一样执行：
- 19/20 题：列竖式数进位，一位一位算。
- 第 32 题：`dfs(0,4)` 手动枚举长度 4 的二进制串，数不含连续 1 的个数。
- 第 24 题：模拟删字符循环，跟踪 `size`、`d` 的变化。
- 技巧：把每个变量的变化写成一行（i, size, d, s, c…），防遗漏。

### 3. 反例思维（对付"判断题"）

判断题要答"这句话**是否一定**成立"。只要找到一个反例即答 F：
- 第 18 题：`s ≤ a 的位数`——找 `a=5, b=95`，`s=2>1`，反例成立 → F。
- 第 23 题："d>10 必崩"——构造"字符全被删、d 耗尽"的情况，不崩 → F。
- 第 17 题："输出可能大于 5"——5 位最多进 5 次，无反例 → F。
- 记住：**判断题找反例，选择题找必然**。

### 4. 复杂度题：数循环与递归层数

- 看循环嵌套：单层 O(n)、双层 O(n²)。
- 数每个元素的"访问次数"：删字符题每个字符入栈 1 次出栈 1 次 → **O(n)**（虽然嵌套 while，但总量恒定）。
- 递归枚举：每层 2 分支、深 n 层 → **2ⁿ**（dfs 题），不是 n²。
- `d` 这类输入参数若不随数据规模增长，不计入复杂度（第 25 题）。

### 5. 功能抽象（对付"功能题"）

看完程序总结一句话功能：
- 删字符题：维护单调栈，删 d 个使**字典序最大**（栈顶 < 新字符就删）——注意方向，别想当然"最小"。
- dfs 题：枚举 + 剪枝，统计满足约束（无连续 1）的方案数。
- 抽象后再回看选项，选最贴切的。

### 6. 常见坑位清单

| 坑 | 例子 |
|----|------|
| 认错输出变量 | 19/20 选了"和"而非进位次数 |
| 边界 `>=` vs `>` | 21 题 `size>=0` 越界 |
| "一定"与"可能" | 17、23 判断题 |
| 递归方向与参数 | 32 题 dfs 少算 |
| 复杂度含无关参数 | 25 题把 d 当规模 |

## 五、程序补全做法（必读）

完善程序题的核心：**读懂算法骨架，把每个空补成让程序正确、自洽的代码**。

### 1. 先整体理解，再填空

补全前必须完成：
1. **读题干**——程序要算什么（有序对个数、骨牌最大异或、次大值之和）。
2. **读完整代码**——看注释、看 main、看循环结构，先画"程序分几步"。
3. **标注变量角色**——每个数组、每个变量是干什么的：

| 题组 | 变量角色 |
|------|---------|
| 有序对 | `num` 不同值个数；`present` 是否出现过；`c[x]` 值 x 上次的 num 快照；`pair` 答案 |
| 骨牌 | `covered` 是否被盖；`a` 数字；`sum` 未覆盖数字异或和；`solve(x,y,sum)` 状态 |
| 次大值 | `p` 排列；`q[值]=位置`；`prev/next` 双向链表（值的大小邻居） |

变量角色不清，填空必错（38/39 败在 num/present 不明；54 题败在 p/q 混淆）。

### 2. 填空技巧

- **按执行顺序逐空推**：从 main 第一个空开始，跟着数据流走（骨牌题 (1) 一定是入口 `solve(0,0,0)`）。
- **分情况讨论**：递归题把"分支"逐个列出来（骨牌：不盖 / 竖盖 / 横盖），每分支填对应递归调用。
- **对称性**：竖/横骨牌结构对称，答案常成对（44 与 45 题同为 `solve(x,y+1,sum)`）。
- **边界/终止条件**：递归终止（`y==m` 换行、`x==n` 返回）先定位，(3) 类填空基本是边界判断。

### 3. 代入验证（最关键）

填完全部空后，**取小样例手跑一遍**，检查每步值是否合理：
- 有序对题：`a=[1,2,1]` 手动数不同值对 = 3，跑程序对 3 则自洽。
- 骨牌题：`2×2` 网格枚举一遍。
- 若某步值突变（如 pair 突然跳变），必是某个空填错。

### 4. 选择题式填空的取舍

- 每空 4 选项，**把候选代入"看哪个让整体逻辑自洽"**，不必凭空造。
- 先排除明显错（方向反、索引错、赋值颠倒），剩 2 选 1 时靠"变量角色"定。
- 43/44/45 全选成 `sum ^ a[x][y]`——没注意"被覆盖的格子不进异或"，代入后应发现矛盾。

### 5. 两类必学模型

**① 回溯枚举（骨牌类）**：状态 `(x,y)`，逐格决策。模板：

```
dfs(x,y,state):
    到边界 → 返回
    情况1：不选 → dfs(下一步, state + 收益)
    情况2：选 → 标记；dfs(下一步, state)；还原
    返回 max(各情况)
```

关键：**决策分支**（不盖/竖/横）、**标记与还原**（covered 设 true 再设 false）、**收益计算**（盖住的不算）。

**② 单调栈/链表（次大值类）**：从大到小处理每个值，用双向链表维护"当前最大值的左右边界"，每个值作为次大值时统计贡献区间。

```
q[值]=位置；prev/next 建链（升序邻居）
按值从大到小：num 的贡献 = num × 左边可选 × 右边可选
删除 num 后：prev[右邻]=左邻，next[左邻]=右邻（接链）
```

## 六、小结

J 组（1–45 题）得分率 48%。基础单选 66.7%、flat_map 概念（46–48、51、52）全对，功底不差；失分集中于**程序阅读（35.1%）与完善（45.5%）**。附加题（提高组）12/30，反获 12 分，但 J 组本分未稳。下步重点：
1. 读程序先认输出变量，勿想当然（加法进位 5 连错之根）。
2. 判断题必找反例，边界（`>=`/`>`、越界）多疑。
3. 补全题先标变量角色，再代入验证；回溯"标记-还原"、单调栈"删点-接链"两模型练熟。
