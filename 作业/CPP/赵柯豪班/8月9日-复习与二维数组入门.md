### 1、<a href="https://fslong.iok.la/problem/ZKH41" target="_blank">三袋零食</a>(100分)

**题目描述**

三个好朋友各买了一袋零食，放在一起称重，重量分别是 a、b、c 克。如果恰好有两袋重量相同（剩下的一袋不同），他们就说"中奖了"。请判断是否中奖。

**输入格式**

一行，三个整数 a、b、c（1 ≤ a, b, c ≤ 1000）。

**输出格式**

一行，若能组成"恰好两袋相同"，输出 `Yes`，否则输出 `No`。

**样例输入 1**

```
3 3 2
```

**样例输出 1**

```
Yes
```

**样例输入 2**

```
2 2 2
```

**样例输出 2**

```
No
```

**样例输入 3**

```
5 6 7
```

**样例输出 3**

```
No
```

**提示**

"恰好两袋相同"要排除三袋全同的情况。可以这样判断：`(a == b && b != c) || (a == c && a != b) || (b == c && a != b)`。

### 2、<a href="https://fslong.iok.la/problem/ZKH42" target="_blank">烘焙温度</a>(100分)

**题目描述**

妈妈做蛋糕，烤箱上的温度表只显示华氏度，可食谱写的是摄氏度。她需要把摄氏温度换算成华氏温度。换算公式为：`F = C × 9 ÷ 5 + 32`。帮她写个换算程序。

**输入格式**

一行，一个两位小数，表示摄氏温度 C（-100.00 ≤ C ≤ 1000.00）。

**输出格式**

一行，输出换算后的华氏温度，保留两位小数。

**样例输入 1**

```
0.00
```

**样例输出 1**

```
32.00
```

**样例输入 2**

```
100.00
```

**样例输出 2**

```
212.00
```

**提示**

用 `double` 存温度，公式算完后用 `printf("%.2f", f)` 保留两位小数，或 `cout << fixed << setprecision(2)`。

### 3、<a href="https://fslong.iok.la/problem/ZKH43" target="_blank">储物柜核对</a>(100分)

**题目描述**

地铁站的储物柜按 n 行 m 列排列，管理员把每个柜子的编号记成一张表格，想核对一遍。输入这张 n 行 m 列的编号表，原样输出出来。

**输入格式**

第一行，两个整数 n 和 m（1 ≤ n, m ≤ 100）。
接下来 n 行，每行 m 个整数，表示柜子编号。

**输出格式**

n 行，每行 m 个整数，与原表一致。同一行的数字之间用一个空格隔开。

**样例输入**

```
3 3
1 2 3
4 5 6
7 8 9
```

**样例输出**

```
1 2 3
4 5 6
7 8 9
```

**提示**

双层循环读入：外层循环控制行，内层循环控制列。输出时注意：一行中除了第一个数，每个数前面加一个空格；每行结束换行。

### 4、<a href="https://fslong.iok.la/problem/ZKH44" target="_blank">货架盘点</a>(100分)

**题目描述**

超市货架有 n 层，每层放 m 个格子，货架编号记成一张 n 行 m 列的表格。店长要盘点编号大于 k 的格子有多少个，好安排补货。请统计这张表格里编号大于 k 的元素个数。

**输入格式**

第一行，两个整数 n 和 m（1 ≤ n, m ≤ 100）。
接下来 n 行，每行 m 个整数，表示货架编号（1 ≤ 编号 ≤ 10000）。
最后一行，一个整数 k（1 ≤ k ≤ 10000）。

**输出格式**

一行，一个整数，为编号大于 k 的格子总数。

**样例输入**

```
3 3
1 2 3
4 5 6
7 8 9
5
```

**样例输出**

```
4
```

**样例解释**

大于 5 的编号有 6、7、8、9，共 4 个。

**提示**

先用双层循环把整张表读进二维数组，再双层循环遍历：只要 `a[i][j] > k` 就让计数器加 1。

### 5、<a href="https://fslong.iok.la/problem/ZKH45" target="_blank">偶数出列</a>(100分)

**题目描述**

班主任把全班 n 个同学的学号按座位顺序记了下来，现在让学号为偶数的同学出列站到一边。请按座位的先后顺序，把学号是偶数的同学挑出来。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 100）。
第二行，n 个整数，表示按座位顺序记录的学号（1 ≤ 学号 ≤ 1000）。

**输出格式**

一行，按原顺序输出所有偶数学号，数字之间用一个空格隔开。如果一个偶数都没有，输出 `0`。

**样例输入**

```
6
1 4 7 8 10 3
```

**样例输出**

```
4 8 10
```

**样例解释**

学号 1、4、7、8、10、3 中，偶数是 4、8、10，按原顺序输出。

**提示**

读进一维数组后遍历，`a[i] % 2 == 0` 就输出。输出时用一个标志记着"是不是第一个输出的数"，不是第一个就在前面加空格。遍历完一个偶数都没输出过，就输出 `0`。
