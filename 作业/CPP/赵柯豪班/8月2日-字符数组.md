### 第 16 题 统计元音 [zkh11]（100 分）— <a href="https://fslong.iok.la/problem/ZKH11" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

冯老师批改英文作文，想统计一段话里元音字母（a、e、i、o、u）一共出现了多少次。输入一行只含小写字母的字符串，请统计其中元音字母的总个数。

**输入格式**

一行，一个只含小写字母的字符串 s（长度 ≤ 100）。

**输出格式**

一行，一个整数，表示元音字母的总个数。

**样例输入**

```
hello
```

**样例输出**

```
2
```

**样例解释**

`hello` 中元音字母有 e、o，共 2 个。

**提示**

用 `char s[105];` 存字符串，`cin >> s;` 读入。用 `for` 循环遍历，逐个判断是否属于 `'a'`、`'e'`、`'i'`、`'o'`、`'u'`，是则计数加 1。

### 第 17 题 字符出现了几次 [zkh12]（100 分）— <a href="https://fslong.iok.la/problem/ZKH12" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

王叔叔管理游戏服务器，想统计某个字母在一条聊天消息里出现了多少次。输入一个字符 c 和一个字符串 s，请统计 c 在 s 中出现的次数。

**输入格式**

第一行，一个字符 c（小写字母）。

第二行，一个只含小写字母的字符串 s（长度 ≤ 100）。

**输出格式**

一行，一个整数，表示 c 在 s 中出现的次数。

**样例输入**

```
o
hello
```

**样例输出**

```
1
```

**样例解释**

`o` 在 `hello` 中出现了 1 次。

**提示**

`cin >> c;` 读字符，`cin >> s;` 读字符串。遍历 s，每当 `s[i] == c` 时计数加 1。

### 第 18 题 大写小写各多少 [zkh13]（100 分）— <a href="https://fslong.iok.la/problem/ZKH13" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

侯老师统计一篇文章里大写字母和小写字母各有多少个。输入一个字符串（可能含大写字母、小写字母和数字），请统计其中大写字母的个数和小写字母的个数。

**输入格式**

一行，一个字符串 s（长度 ≤ 100，可能含大写字母、小写字母和数字）。

**输出格式**

一行，两个整数，依次为小写字母个数和大写字母个数，用空格隔开。

**样例输入**

```
Hello123
```

**样例输出**

```
4 1
```

**样例解释**

`Hello123` 中：小写字母 e、l、l、o 共 4 个，大写字母 H 共 1 个，数字 123 不计入。

**提示**

遍历字符串，`c >= 'a' && c <= 'z'` 是小写，`c >= 'A' && c <= 'Z'` 是大写，分别计数。

### 第 20 题 手机号里有几个数字 [zkh15]（100 分）— <a href="https://fslong.iok.la/problem/ZKH15" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

侯老师收集了一份作业登记信息，里面混着字母和数字。他想知道：其中一共出现了多少个数字字符（`'0'` 到 `'9'`）。输入一个字符串，请统计其中数字字符的个数。

```
abc123xyz4
```

```
4
```

**提示**

遍历字符串，判断 `s[i] >= '0' && s[i] <= '9'`，是则计数加 1。
