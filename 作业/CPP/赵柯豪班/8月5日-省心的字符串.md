### 第 16 题 密保口令 [zkh21]（100 分）— <a href="https://fslong.iok.la/problem/ZKH21" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

游戏账号的密保口令由前后两段组成，需要拼在一起才是完整口令。输入两段口令，把第二段拼接到第一段末尾，输出完整口令。

**输入格式**

第一行，字符串 a（不含空格）。
第二行，字符串 b（不含空格）。

**输出格式**

一行，拼接后的完整口令。

**样例输入**

```
abc
bcd
```

**样例输出**

```
abcbcd
```

**提示**

`string` 用 `+` 可以直接拼接：`cout << a + b;`，也可以用 `a += b;` 或 `a.append(b);`。

### 第 17 题 隔位读取件码 [zkh22]（100 分）— <a href="https://fslong.iok.la/problem/ZKH22" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

快递站取的取件码是一串字符，站长规定只看第 2、4、6、8……位（从 1 开始数）。输入一个字符串，请输出这些位置的字符。

**输入格式**

一行，一个不含空格的字符串 s。

**输出格式**

一行，s 中第 2、4、6、8……位（从 1 开始数）的字符。

**样例输入**

```
HelloWorld
```

**样例输出**

```
elWrd
```

**提示**

字符串下标从 0 开始，第 2 位对应 `s[1]`。用 `for (int i = 1; i < s.size(); i += 2)` 输出 `s[i]`。

### 第 18 题 拆分单词 [zkh23]（100 分）— <a href="https://fslong.iok.la/problem/ZKH23" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

英语老师把一篇短文发给学生，短文里全是空格分隔的单词。她想把每个单词单独一行打印出来，方便学生逐个背诵。输入一行若干个单词，请把每个单词分行输出。

**输入格式**

一行，若干个由空格分隔的单词。

**输出格式**

若干行，每行一个单词。

**样例输入**

```
I am learning English
```

**样例输出**

```
I
am
learning
English
```

**提示**

`cin >>` 读 string 时遇到空格就停止，所以 `while (cin >> w)` 可以一次读入一个单词，读到输入结束为止。

### 第 19 题 句子长度 [zkh24]（100 分）— <a href="https://fslong.iok.la/problem/ZKH24" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

妈妈发朋友圈，想知道每句话有多少个字（含空格）。输入若干行句子，请输出每行句子的长度。

**输入格式**

第一行，一个整数 T，表示句子的行数。
接下来 T 行，每行一个字符串（含空格）。

**输出格式**

T 行，每行一个整数，依次为每行字符串的长度。

**样例输入**

```
2
Hello World
C++ is fun
```

**样例输出**

```
11
10
```

**提示**

读入 T 后要先用 `cin.ignore()` 吃掉换行符，再循环调用 `getline(cin, s)`，最后用 `s.size()` 求长度。

### 第 20 题 群公告复读机 [zkh25]（100 分）— <a href="https://fslong.iok.la/problem/ZKH25" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

冯老师在群里发公告，要求复读机模式输出：第 1 行原样输出，之后每行开头多一个空格。输入复读次数和一句公告，按要求输出。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 100），表示复读次数。
第二行，一句公告，含空格。

**输出格式**

n 行，第 i 行开头有 i-1 个空格，后面跟上公告内容。

**样例输入**

```
3
I am happy
```

**样例输出**

```
I am happy
 I am happy
  I am happy
```

**提示**

读入 n 后先 `cin.ignore()`，再用 `getline(cin, s)` 读整行公告。输出时第 i 行先打印 i 个空格再输出 s。
