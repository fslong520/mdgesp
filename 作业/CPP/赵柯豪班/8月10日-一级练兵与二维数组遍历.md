### 1、<a href="https://fslong.iok.la/problem/ZKH46" target="_blank">偶数的奖金</a>(100分)

**题目描述**

社区办抽奖活动，奖券编号从 a 到 b。规则是：编号为偶数的奖券都有奖金，奖金额度等于它的编号。请你算一算，从 a 到 b（包括 a 和 b）所有偶数的编号加起来一共是多少。

**输入格式**

第一行，一个整数 T，表示有 T 组数据。
接下来 T 行，每行两个整数 a、b。

**输出格式**

T 行，每行一个整数，表示这组 a 到 b 之间所有偶数之和。

**样例输入 1**

```
2
1 10
-10 10
```

**样例输出 1**

```
30
0
```

**样例解释**

1 到 10 的偶数是 2、4、6、8、10，和为 30；-10 到 10 的偶数是 -10、-8、…、0、…、10，正负抵消，和为 0。

**提示**

用 `while (T--)` 循环处理多组数据。每组里用 `for` 从 a 遍历到 b，`i % 2 == 0` 就累加。注意 a、b 可能是负数，累加结果用 `long long` 更保险。

### 2、<a href="https://fslong.iok.la/problem/ZKH47" target="_blank">手环记体温</a>(100分)

**题目描述**

赵柯豪戴的健康手环连续记录了 N 天的体温。体温用扩大 100 倍的整数表示（比如 36.50°C 记作 3650）。

第 1 天的体温是 W，从第 2 天开始，每天记录的是**相对前一天的变化量** Ai（比如第 2 天比第 1 天高了 0.50°C，Ai 就是 50）。

人体正常体温范围是 36.00°C 到 37.00°C，对应整数 3600 到 3700（含边界）。请统计这 N 天里体温正常的天数。

**输入格式**

第一行，一个整数 N，表示记录天数。
第二行，一个整数 W，表示第 1 天的体温。
第三行，N - 1 个整数，表示从第 2 天开始的每天变化量。

**输出格式**

一行，一个整数，表示体温正常的天数。

**样例输入 1**

```
5
3500
50 30 20 40
```

**样例输出 1**

```
2
```

**样例解释 1**

每天体温依次为：3500、3550、3580、3600、3640。正常范围是 3600 到 3700，其中 3600、3640 正常，共 2 天。

**样例输入 2**

```
5
3800
-100 -50 0 -100
```

**样例输出 2**

```
3
```

**样例解释 2**

每天体温：3800、3700、3650、3650、3550。其中 3700、3650、3650 在正常范围内，共 3 天。

**提示**

用一个变量 `now` 记当前体温，初始为 W。每读到一个变化量 `now += x`，判断 `now` 是否在 3600 到 3700 之间，是就计数。第 1 天也要判断。

### 3、<a href="https://fslong.iok.la/problem/ZKH48" target="_blank">货架每层总价</a>(100分)

**题目描述**

超市货架有 n 层，每层有 m 个格子，每格放一件商品，价格记成一张 n 行 m 列的表格。店长想把每一层的商品总价算出来贴标签。请输出每一层的总价。

**输入格式**

第一行，两个整数 n 和 m（1 ≤ n, m ≤ 100）。
接下来 n 行，每行 m 个整数，表示货架价格（1 ≤ 价格 ≤ 10000）。

**输出格式**

一行，n 个整数，依次是第 1 层到第 n 层的总价，数字之间用一个空格隔开。

**样例输入**

```
3 3
1 2 3
4 5 6
7 8 9
```

**样例输出**

```
6 15 24
```

**样例解释**

第 1 层：1+2+3=6；第 2 层：4+5+6=15；第 3 层：7+8+9=24。

**提示**

外层循环控制层（行），内层循环遍历这一层的 m 个格子，用一个变量累加当前行，算完一行就输出并清零。

### 4、<a href="https://fslong.iok.la/problem/ZKH49" target="_blank">方桌对角线</a>(100分)

**题目描述**

火锅店的包间里摆着一张 n×n 的方桌，座位号排成一个方阵。老板想给主对角线（左上角到右下角）座位上的客人送小菜，需要先知道这些座位的号码加起来是多少。请计算主对角线上所有座位号之和。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 100）。
接下来 n 行，每行 n 个整数，表示座位号（1 ≤ 座位号 ≤ 10000）。

**输出格式**

一行，一个整数，为主对角线上座位号的总和。

**样例输入**

```
3
1 2 3
4 5 6
7 8 9
```

**样例输出**

```
15
```

**样例解释**

主对角线元素是 1、5、9，和为 15。

**提示**

主对角线上的元素满足行号等于列号：`a[i][i]`。用一个 `for` 循环，`i` 从 0 到 n-1，累加 `a[i][i]` 即可，不需要双层循环。

### 5、<a href="https://fslong.iok.la/problem/ZKH50" target="_blank">最贵摊位</a>(100分)

**题目描述**

菜市场的摊位按 n 行 m 列排开，每个摊位卖的东西价格不同，价格记成一张 n 行 m 列的表格。妈妈想知道全场最贵的摊位在哪儿、卖多少钱。请找出价格最大的摊位，输出它的价格和位置（第几行第几列，从 1 开始数）。如果价格一样贵的摊位有好几个，输出**行号最小**的那个；行号也一样，就输出**列号最小**的那个。

**输入格式**

第一行，两个整数 n 和 m（1 ≤ n, m ≤ 100）。
接下来 n 行，每行 m 个整数，表示摊位价格（1 ≤ 价格 ≤ 100000）。

**输出格式**

第一行，一个整数，为最大价格。
第二行，两个整数，为最大价格摊位所在的行号和列号（从 1 开始）。

**样例输入**

```
2 3
5 9 3
9 2 8
```

**样例输出**

```
9
1 2
```

**样例解释**

价格最大是 9，出现在两个位置：第 1 行第 2 列和第 2 行第 1 列。按规则取行号最小的，输出第 1 行第 2 列，即 `1 2`。

**提示**

遍历时用变量记录当前最大值和它的行、列（记 1 起始的行列）。只有遇到**严格大于**当前最大值的数才更新，这样多个最大值时会自然保留行号、列号更小的那个。
