### 第 16 题 超市购物 [zkh06]（100 分）— <a href="https://fslong.iok.la/problem/ZKH06" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

冯阿姨去超市买菜，买了青菜 x 元、肉 y 元、水果 z 元，给收银员 100 元。请计算这三样菜一共多少钱，以及收银员应找回多少钱。

**输入格式**

一行，三个整数 x、y、z（1 ≤ x, y, z ≤ 50），分别表示青菜、肉、水果的价格。

**输出格式**

两行，第一行为总价，第二行为应找回的钱。

**样例输入**

```
20 35 15
```

**样例输出**

```
70
30
```

**提示**

总价 = x + y + z，找零 = 100 − 总价。按顺序计算、输出即可。

### 第 18 题 跑步打卡 [zkh08]（100 分）— <a href="https://fslong.iok.la/problem/ZKH08" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

冯阿姨坚持晨跑，第 1 天跑 1 圈，之后每天比前一天多跑 1 圈。输入晨跑天数 n，输出这 n 天一共跑了多少圈。

**输入格式**

一行，一个整数 n（1 ≤ n ≤ 100），表示天数。

**输出格式**

一行，一个整数，表示总共跑的圈数。

**样例输入 1**

```
3
```

**样例输出 1**

```
6
```

第 1 到 3 天分别跑 1、2、3 圈，共 1+2+3=6 圈。

**样例输入 2**

```
5
```

**样例输出 2**

```
15
```

第 1 到 5 天分别跑 1、2、3、4、5 圈，共 1+2+3+4+5=15 圈。

**提示**

用 for 循环从 1 累加到 n，把每天跑的圈数加进一个变量，最后输出。

### 第 19 题 最受欢迎动物投票 [zkh09]（100 分）— <a href="https://fslong.iok.la/problem/ZKH09" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

Minecraft 服务器举办"最受欢迎动物"评选。候选动物有 6 种：1 羊、2 牛、3 猪、4 鸡、5 狼、6 猫。每个玩家把票投给自己最喜欢的动物（票上写的是动物编号）。请你统计每只动物的得票数，输出得票最多的动物编号；若多种动物平票，输出编号最小的那种。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000），表示票数。
第二行，n 个整数，表示每张票投给的动物编号（1 ≤ 编号 ≤ 6）。

**输出格式**

一行，一个整数，表示得票最多的动物编号。

**样例输入 1**

```
10
1 2 1 3 2 2 1 2 3 2
```

**样例输出 1**

```
2
```

**样例解释 1**

1 号羊 3 票、2 号牛 5 票、3 号猪 2 票，2 号牛票数最多。

**样例输入 2**

```
8
1 2 1 3 2 3 1 3
```

**样例输出 2**

```
1
```

**样例解释 2**

1 号羊 3 票、2 号牛 2 票、3 号猪 3 票。1 号和 3 号平票，取编号较小者 1 号。

**提示**

计数排序思想：建计数数组 `cnt[7]`（下标 1~6 对应 6 种动物），读到票号 x 就执行 `cnt[x]++`。统计完遍历找票数最多的编号。注意平票取编号小者——只有票数**严格大于**当前最大值时才更新，平票时保持原编号即可。

### 第 20 题 骰子点数统计 [zkh10]（100 分）— <a href="https://fslong.iok.la/problem/ZKH10" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

王叔叔带儿子在游乐园玩掷骰子游戏，一共掷了 n 次。请你统计每个点数（1-6）各出现了多少次，按 1 到 6 的顺序输出。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000）。
第二行，n 个整数，表示每次掷出的点数（1 ≤ 点数 ≤ 6）。

**输出格式**

6 行，每行格式为 `点数:次数`，按点数 1 到 6 输出。

**样例输入**

```
7
3 1 3 6 2 3 5
```

**样例输出**

```
1:1
2:1
3:3
4:0
5:1
6:1
```

**提示**

计数排序基础应用：建计数数组 `cnt[7]`（下标 1~6 对应每个点数），读到点数 x 就执行 `cnt[x]++`。最后从 1 到 6 输出每个点数的出现次数。
