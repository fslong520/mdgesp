### 第 16 题 消息长度检查 [zkh16]（100 分）— <a href="https://fslong.iok.la/problem/ZKH16" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

王叔叔的游戏服务器规定，一条聊天消息最长 20 个字符。输入一个字符串，用 `strlen` 求出它的长度并输出。

**输入格式**

一行，一个不含空格的字符串 s（长度 ≤ 100）。

**输出格式**

一行，一个整数，表示 s 的长度。

**样例输入**

```
hello
```

**样例输出**

```
5
```

**提示**

`strlen(s)` 会返回字符串有效字符的个数，不含结尾的 `'\0'`。

### 第 17 题 拼接头像昵称 [zkh17]（100 分）— <a href="https://fslong.iok.la/problem/ZKH17" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

妈妈要给快递单生成收件人信息，把"收件人"和"电话"两段文字拼成一行。输入两个字符串 a 和 b，用 `strcpy` 和 `strcat` 把 b 拼接到 a 的末尾，输出拼接结果。

**输入格式**

第一行，字符串 a（不含空格，长度 ≤ 100）。

第二行，字符串 b（不含空格，长度 ≤ 100）。

**输出格式**

一行，拼接后的字符串。

**样例输入**

```
Zhang
13800138000
```

**样例输出**

```
Zhang13800138000
```

**提示**

`strcat(a, b)` 会把 b 的内容接到 a 后面，并自动补上 `'\0'`。拼接时注意数组 a 要开足够大的空间。

### 第 18 题 会员码全大写 [zkh18]（100 分）— <a href="https://fslong.iok.la/problem/ZKH18" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

王叔叔的便利店给会员发会员码，需要把里面的小写字母全部转成大写。输入一个字符串（可能含大小写字母和数字），把其中的小写字母转成大写后输出。

**输入格式**

一行，一个字符串 s（长度 ≤ 100，可能含字母和数字）。

**输出格式**

一行，转换后的字符串。

**样例输入**

```
Hello123
```

**样例输出**

```
HELLO123
```

**提示**

小写字母 ASCII 码比对应大写字母大 32，小写转大写可 `s[i] -= 32;`，也可以用 `toupper(s[i])`。

### 第 19 题 字典顺序 [zkh19]（100 分）— <a href="https://fslong.iok.la/problem/ZKH19" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

侯老师整理班级花名册，需要按字典序比较两个名字。输入两个字符串，用 `strcmp` 比较：如果第一个字符串比第二个小，输出 -1；两个相等，输出 0；第一个比第二个大，输出 1。

**输入格式**

第一行，字符串 a（长度 ≤ 100）。

第二行，字符串 b（长度 ≤ 100）。

**输出格式**

一行，一个整数，为 -1、0 或 1。

**样例输入**

```
abc
abd
```

**样例输出**

```
-1
```

**提示**

`strcmp(a, b)` 返回负数、0、正数三种情况，对应 a 比 b 小、相等、比 b 大。

### 第 20 题 名单核对 [zkh20]（100 分）— <a href="https://fslong.iok.la/problem/ZKH20" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

侯老师手上有两份作业名单，他想确认两份名单是否完全一致。输入两个字符串，用 `strcmp` 判断：完全相同输出 `SAME`，否则输出 `DIFFERENT`。

**输入格式**

第一行，字符串 a（长度 ≤ 100）。

第二行，字符串 b（长度 ≤ 100）。

**输出格式**

一行，`SAME` 或 `DIFFERENT`。

**样例输入**

```
Zhang
Zhang
```

**样例输出**

```
SAME
```

**提示**

`strcmp(a, b) == 0` 表示两个字符串完全相同。
