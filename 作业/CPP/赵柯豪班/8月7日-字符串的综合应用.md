### 1、<a href="https://fslong.iok.la/problem/ZKH31" target="_blank">短信净化</a>(100分)

**题目描述**

妈妈的手机短信被乱七八糟的符号刷屏，她决定把连续的非数字字符统统换成一个大 `*`，数字原样保留。帮她净化短信。

**输入格式**

一行字符串 s（可能含空格，长度 ≤ 1000）。

**输出格式**

一行，净化后的字符串：数字保留，连续的非数字字符只留一个 `*`。

**样例输入**

```
$Ts!47&*s456  a23* +B9
```

**样例输出**

```
*47*456*23*9
```

**提示**

数字直接拼到答案；非数字只有答案末尾不是 `*` 时才加一个 `*`。可能含空格，用 `getline(cin, s)` 读入。

### 2、<a href="https://fslong.iok.la/problem/ZKH32" target="_blank">菜价大作战</a>(100分)

**题目描述**

妈妈买菜回来，小票上的价格数字全和字母糊在一起了。她只想知道所有数字加起来是多少。帮她算一算。

**输入格式**

一行，由小写字母和数字组成的字符串 s（长度 ≤ 1000）。

**输出格式**

一个整数，为 s 中所有数字字符的数值之和。

**样例输入**

```
a1b2c3
```

**样例输出**

```
6
```

**样例解释**

`a1b2c3` 里的数字字符是 1、2、3，和为 `1 + 2 + 3 = 6`。

**提示**

遍历字符串，遇到数字字符就 `c - '0'` 转成数字累加。单个数字直接相加即可，不用把连续数字拼成整数。

### 3、<a href="https://fslong.iok.la/problem/ZKH33" target="_blank">姓名排座</a>(100分)

**题目描述**

侯老师要给全班同学按姓名的字典序排座次，说"先来后到不如按字母排队"。帮他排序。

**输入格式**

第一行，一个整数 N（1 ≤ N ≤ 100）。
接下来 N 行，每行一个小写字母组成的姓名（长度 ≤ 50）。

**输出格式**

N 行，按字典序从小到大输出每个姓名。

**样例输入**

```
3
wang
liying
anqian
```

**样例输出**

```
anqian
liying
wang
```

**提示**

`string` 之间可以直接用 `<`、`>` 按字典序比较，姓名排序和数字排序思路一样，用选择排序即可。

### 4、<a href="https://fslong.iok.la/problem/ZKH34" target="_blank">锦鲤号码</a>(100分)

**题目描述**

王叔叔的抽奖券上印着一串字符，规则说：里面最大的那个数字就是幸运数字。帮他找出来。

**输入格式**

一行，由小写字母和数字组成的字符串 s（长度 ≤ 1000）。

**输出格式**

一个字符，为 s 中最大的数字字符。若没有数字，输出 `0`。

**样例输入**

```
a3b9c5
```

**样例输出**

```
9
```

**提示**

遍历字符串，用变量记录当前最大的数字字符（初始化为 `'0'`），数字字符之间用 `>` 比较 ASCII 码即可。

### 5、<a href="https://fslong.iok.la/problem/ZKH35" target="_blank">改稿子</a>(100分)

**题目描述**

妈妈写文章总爱用某个词，爸爸看腻了，让她把文章里这个词全部换成新词（单词的前缀、后缀里的也算）。帮她改稿子。

**输入格式**

第一行，一篇文章 s（含空格，长度 ≤ 1000）。
第二行，要被替换的词 a（不含空格）。
第三行，替换成的词 b（不含空格）。

**输出格式**

一行，替换后的文章。

**样例输入**

```
You want someone to help you。  You want someone to like you。
You
I
```

**样例输出**

```
I want someone to help you。  I want someone to like you。
```

**提示**

用 `find()` 从某个位置开始找 a，找到就用 `replace()` 替换，然后把查找起点挪到新词末尾继续找，直到 `find` 返回 `string::npos`。文章含空格，用 `getline` 读入。
