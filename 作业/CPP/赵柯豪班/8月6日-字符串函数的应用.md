### 1、<a href="https://fslong.iok.la/problem/ZKH26" target="_blank">寻找关键词</a>(100分)

**题目描述**

王叔叔的便利店搞"神秘关键词"抽奖：顾客留言里藏着一个词，找到就送辣条。帮忙找出关键词在留言中第一次出现的位置。

**输入格式**

第一行，一个整数 T（1 ≤ T ≤ 10），表示留言条数。
接下来 T 组，每组两行：第一行原文 s，第二行关键词 t（均不含空格）。

**输出格式**

T 行，每行一个整数：t 在 s 中第一次出现的位置（从 0 开始）；找不到则输出 -1。

**样例输入**

```
2
I love C++
love
hello world
abc
```

**样例输出**

```
2
-1
```

**提示**

`s.find(t)` 返回 t 第一次出现的下标；找不到时返回 `string::npos`（一个很大的数）。判断找不到可用 `if (s.find(t) == string::npos)` 输出 -1。

### 2、<a href="https://fslong.iok.la/problem/ZKH27" target="_blank">手机号藏一半</a>(100分)

**题目描述**

王叔叔的快递站怕手机号泄露，取件通知上的手机号要打码：只露中间四位，跟相亲节目嘉宾的脸一样神秘。帮忙把中间四位抠出来。

**输入格式**

第一行，一个整数 T（1 ≤ T ≤ 10）。
接下来 T 行，每行一个 11 位数字手机号。

**输出格式**

T 行，每行输出该手机号中间四位（第 4 位到第 7 位）。

**样例输入**

```
2
13812345678
13598765432
```

**样例输出**

```
1234
9876
```

**提示**

手机号下标从 0 开始，中间四位是下标 3、4、5、6，用 `s.substr(3, 4)` 一次取出。

### 3、<a href="https://fslong.iok.la/problem/ZKH28" target="_blank">群聊插话</a>(100分)

**题目描述**

王叔叔觉得群里的话不够长，非要插一句才过瘾。给定原话和要插的词，把词插到指定位置。

**输入格式**

第一行，一个整数 T（1 ≤ T ≤ 10）。
接下来 T 组，每组三行：第一行原话 s，第二行要插的词 w，第三行插入位置 pos（0 ≤ pos ≤ s 的长度，均不含空格）。

**输出格式**

T 行，每行插入后的字符串。

**样例输入**

```
2
Hello
!
5
abcd
XY
2
```

**样例输出**

```
Hello!
abXYcd
```

**提示**

`insert(pos, w)` 把 w 插到下标 pos 前面，如 `"abcd"` 在位置 2 插 `"XY"` 得 `"abXYcd"`。

### 4、<a href="https://fslong.iok.la/problem/ZKH29" target="_blank">橡皮擦一段</a>(100分)

**题目描述**

冯老师给学生写评语，写到一半觉得中间一段不妥，抄起橡皮就擦。给定评语、起始位置和长度，把中间一段擦掉。

**输入格式**

第一行，一个整数 T（1 ≤ T ≤ 10）。
接下来 T 组，每组三行：第一行评语 s，第二行起始位置 pos，第三行擦除长度 len（均不含空格，保证 pos+len ≤ s 的长度）。

**输出格式**

T 行，每行擦除后的字符串。

**样例输入**

```
2
abcdef
2
2
HelloWorld
5
5
```

**样例输出**

```
abef
Hello
```

**提示**

`erase(pos, len)` 从下标 pos 开始删 len 个字符，如 `"abcdef"` 从位置 2 删 2 个得 `"abef"`。

### 5、<a href="https://fslong.iok.la/problem/ZKH30" target="_blank">涂改带重写</a>(100分)

**题目描述**

妈妈给儿子批作业，觉得一段话写得歪七扭八，用涂改带糊掉重写。给定原话、新词、起始位置和长度，把指定位置的一段换成新词。

**输入格式**

第一行，一个整数 T（1 ≤ T ≤ 10）。
接下来 T 组，每组四行：第一行原话 s，第二行新词 w，第三行起始位置 pos，第四行替换长度 len（均不含空格，保证 pos+len ≤ s 的长度）。

**输出格式**

T 行，每行替换后的字符串。

**样例输入**

```
2
Hello
AB
0
2
abcdef
XY
2
2
```

**样例输出**

```
ABllo
abXYef
```

**提示**

`replace(pos, len, w)` 把下标 pos 起的 len 个字符换成 w，如 `"Hello"` 从位置 0 换 2 个为 `"AB"` 得 `"ABllo"`。
