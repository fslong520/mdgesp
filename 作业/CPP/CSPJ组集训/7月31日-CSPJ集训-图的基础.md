## 图的基础知识点总结

### 1. 基本概念

- **图**：由顶点集 V 和边集 E 组成，记作 G = (V, E)
- **无向图**：边无方向，用 (u, v) 表示
- **有向图**：边有方向，用 <u, v> 表示
- **完全图**：任意两顶点间都有边
  - 无向完全图边数 = n(n-1)/2
  - 有向完全图边数 = n(n-1)
- **零图**：边集为空，仅含孤立顶点
- **度**：
  - 无向图：顶点度 = 与该点相连的边数
  - 有向图：入度（指向该点）+ 出度（从该点出发）
  - **握手定理**：所有顶点度数之和 = 2 × 边数
  - 有向图中入度之和 = 出度之和 = 边数
- **连通**：
  - 连通图：任意两顶点间有路径
  - 连通分量：无向图的极大连通子图
  - n 个顶点的连通图至少需 n-1 条边

### 2. 图的存储

| 存储方式 | 空间复杂度 | 适用场景 | 判边时间 |
|---------|-----------|---------|---------|
| 邻接矩阵 | O(n²) | 稠密图 | O(1) |
| 邻接表 | O(n + m) | 稀疏图 | O(度(v)) |
| 链式前向星 | O(n + m) | 竞赛常用 | O(度(v)) |

### 3. 图的遍历

- **深度优先搜索（DFS）**：用栈（递归），一条路走到黑，回溯
- **广度优先搜索（BFS）**：用队列，层层扩展
- 时间复杂度：均为 O(n + m)（邻接表）

### 4. 拓扑排序

对有向无环图（DAG）的顶点进行线性排序，使得每条边 u→v 中 u 排在 v 之前。

### 5. 参考代码

#### 邻接表存图 + DFS

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<int> g[N];
bool vis[N];

void dfs(int u) {
    vis[u] = true;
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u); // 无向图
    }
    dfs(1);
    return 0;
}
```

#### 邻接表存图 + BFS

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<int> g[N];
bool vis[N];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    queue<int> q;
    q.push(1);
    vis[1] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
        }
    }
    return 0;
}
```

#### 统计各顶点的度

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    for (int i = 1; i <= n; i++)
        cout << g[i].size() << " \n"[i == n];
    return 0;
}
```

### 第 1 题 图的度数统计（100 分）— <a href="https://fslong.iok.la/problem/P9849" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

给定一个 n 个顶点、m 条边的无向图，顶点编号为 1 ∼ n。请你计算每个顶点的度数。

**输入格式**

第一行两个整数 n 和 m，表示顶点数和边数。

接下来 m 行，每行两个整数 u, v，表示一条无向边。

**输出格式**

输出一行 n 个整数，依次表示顶点 1 到顶点 n 的度数，相邻整数之间用空格隔开。

**样例输入**

```
5 4
1 2
1 3
2 4
3 5
```

**样例输出**

```
2 2 2 1 1
```

**样例解释**

顶点 1 与 2、3 相连，度为 2；顶点 2 与 1、4 相连，度为 2；顶点 3 与 1、5 相连，度为 2；顶点 4 与 2 相连，度为 1；顶点 5 与 3 相连，度为 1。

**提示**

- 用 deg[u]++、deg[v]++ 统计即可
- 注意无向图每条边对两端顶点各贡献 1 度

**数据范围**

对于 30% 的数据，1 ≤ n ≤ 100，1 ≤ m ≤ 500。  
对于 60% 的数据，1 ≤ n ≤ 10³，1 ≤ m ≤ 10⁴。  
对于 100% 的数据，1 ≤ n ≤ 10⁵，1 ≤ m ≤ 10⁵。

### 第 2 题 边判定（100 分）— <a href="https://fslong.iok.la/problem/P9850" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

给定一个 n 个顶点、m 条边的无向图，顶点编号为 1 ∼ n。再给定两个顶点 u 和 v，请判断 u 和 v 之间是否有边直接相连。

**输入格式**

第一行两个整数 n 和 m，表示顶点数和边数。

接下来 m 行，每行两个整数 a, b，表示一条无向边。

最后一行两个整数 u, v，表示待查询的两个顶点。

**输出格式**

若 u 和 v 之间有直接边，输出 `Yes`；否则输出 `No`。

**样例输入 1**

```
4 3
1 2
2 3
3 4
1 3
```

**样例输出 1**

```
No
```

**样例解释 1**

顶点 1 和 3 之间无直接边（1 连 2，3 连 2 和 4），故 No。

**样例输入 2**

```
4 3
1 2
2 3
3 4
2 3
```

**样例输出 2**

```
Yes
```

**样例解释 2**

顶点 2 和 3 之间有直接边，故 Yes。

**提示**

- 可用二维数组（邻接矩阵）存储边信息
- 无向图中边 (a,b) 意味着 adj[a][b] = adj[b][a] = true

**数据范围**

对于 30% 的数据，1 ≤ n ≤ 100，1 ≤ m ≤ 500。  
对于 60% 的数据，1 ≤ n ≤ 10³，1 ≤ m ≤ 10⁴。  
对于 100% 的数据，1 ≤ n ≤ 10⁴，1 ≤ m ≤ 10⁵。
