### 程序一：栈实现 DFS 遍历（10 分）

对如下结构的树执行 `travel` 函数：

```
    1
   / \
  2   3
 / \
4   5
```

```cpp
struct Node {
    int val;
    Node *left, *right;
    Node(int v) : val(v), left(nullptr), right(nullptr) {}
};

void travel(Node* root) {
    if (!root) return;
    stack<Node*> s;
    s.push(root);
    while (!s.empty()) {
        Node* cur = s.top(); s.pop();
        cout << cur->val << " ";
        if (cur->right) s.push(cur->right);
        if (cur->left) s.push(cur->left);
    }
}
```

const int N = 100005;
vector<int> g[N];

void bfs(int start) {
    queue<int> q;
    q.push(start);
    vis[start] = true;

## 图的遍历知识点总结

### 1. 深度优先搜索（DFS）

- **思想**：一条路走到黑，走不通就回溯
- **实现**：递归 或 显式栈
- **访问顺序**：先深入后返回，类似树的前序遍历
- 使用栈的原因：后进先出，与递归天然对应
- 代码中必须用 visited 数组标记，防止重复访问

### 2. 广度优先搜索（BFS）

- **思想**：层层推进，先访问离起点最近的顶点
- **实现**：队列
- **访问顺序**：按层次从近到远
- 使用队列的原因：先进先出，保证按层扩展
- **性质**：无权图中，BFS 首次到达某点的路径即最短路径
- 入队时即标记 visited，防止重复入队

### 3. 图的连通性

- **连通图**：任意两顶点间都有路径
- **连通分量**：无向图的极大连通子图
- **连通图最少边数**：n 个顶点的连通图至少需 n-1 条边（树形）
- **删边成树**：连通图 m 条边、n 个顶点，删去 m-n+1 条边即成树
- **遍历与连通**：从连通图任一顶点出发的 DFS/BFS 可访问全部顶点；非连通图只能访问所在连通分量

### 4. 遍历算法比较

| 项目 | DFS | BFS |
|------|-----|-----|
| 辅助结构 | 栈（递归） | 队列 |
| 访问顺序 | 纵深优先 | 按层扩展 |
| 时间复杂度 | O(n+m) | O(n+m) |
| 空间复杂度 | O(n) | O(n) |
| 适用场景 | 路径搜索、回溯、连通性 | 无权最短路、层次遍历 |

#### 洪水填充（BFS 版）

```cpp
#include <bits/stdc++.h>
using namespace std;

int dx[4] = {1, -1, 0, 0};
int dy[4] = {0, 0, 1, -1};
char a[105][105];
bool vis[105][105];

void flood_fill(int sx, int sy, int n, int m, char old_c, char new_c) {
    queue<pair<int,int>> q;
    q.push({sx, sy});
    a[sx][sy] = new_c;
    vis[sx][sy] = true;
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (vis[nx][ny] || a[nx][ny] != old_c) continue;
            vis[nx][ny] = true;
            a[nx][ny] = new_c;
            q.push({nx, ny});
        }
    }
}
```

**题目描述**

某学校的校园网由 n 台电脑和 n-1 根网线连接而成，整张网络连通且没有环（即形成一棵树）。

信息从一台电脑发出后，每秒钟沿网线传到相邻的一台电脑。请你计算：从某台电脑到另一台电脑传递信息**最多需要多少秒**（即树上任意两台电脑之间距离的最大值）。

**输入格式**

第一行一个整数 n，表示电脑台数。

接下来 n-1 行，每行两个整数 u, v，表示电脑 u 和 v 之间有一根网线。

**输出格式**

输出一个整数，表示传递信息最多需要的秒数。

**样例输入**

```
5
1 2
1 3
2 4
2 5
```

**样例输出**

```
3
```

**样例解释**

网络结构：

```
    1
   / \
  2   3
 / \
4   5
```

电脑 4 传信息到电脑 3 需经过 4→2→1→3，共 3 秒；电脑 5 到电脑 3 同样 3 秒。没有两台电脑距离超过 3 秒，故答案为 3。

**提示**

- 先任选一台电脑（如 1 号）做一次 BFS，找到离它最远的电脑 u
- 再从 u 出发做一次 BFS，u 到最远电脑的距离即为答案
- 为什么两步就够？想想：树上离任意点最远的点，一定是直径的端点

**数据范围**

对于 30% 的数据，1 ≤ n ≤ 100。  
对于 60% 的数据，1 ≤ n ≤ 10³。  
对于 100% 的数据，1 ≤ n ≤ 10⁵。
