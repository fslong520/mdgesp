## 哈夫曼编码知识点总结

### 1. 基本概念

- **哈夫曼树（最优二叉树）**：给定 n 个权值作为叶子节点，构造一棵二叉树，使带权路径长度（WPL）最小
- **带权路径长度（WPL）**：所有叶子节点的权值 × 该叶子到根的路径长度之和
- **哈夫曼编码**：基于哈夫曼树的前缀编码，高频字符用短码，低频用长码

### 2. 构建步骤（贪心算法）

1. 将 n 个权值看作 n 棵只有根节点的二叉树
2. 从森林中选两棵根节点权值最小的树合并，新根权值为二者之和
3. 将新树放回森林
4. 重复 2~3 步，直到只剩一棵树

### 3. 重要性质

- 哈夫曼树中无度为 1 的节点
- n 个叶子 → 总节点数为 2n - 1
- 合并次数为 n - 1
- 编码是前缀编码，唯一可译
- 编码结果不唯一（左右孩子分配可互换），但 WPL 唯一

### 4. 编码方法

- 左分支标记 0，右分支标记 1（或相反）
- 从根到叶子路径上的 0/1 序列即为该字符编码

### 5. 参考代码

#### 用小根堆计算 WPL

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, x;
    cin >> n;
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int i = 0; i < n; i++) {
        cin >> x;
        pq.push(x);
    }
    int wpl = 0;
    while (pq.size() > 1) {
        int a = pq.top(); pq.pop();
        int b = pq.top(); pq.pop();
        int sum = a + b;
        wpl += sum;
        pq.push(sum);
    }
    cout << wpl << '\n';
    return 0;
}
```

#### 生成哈夫曼编码（链式版）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    char ch;
    int w;
    Node *l, *r;
    Node(char c, int w) : ch(c), w(w), l(nullptr), r(nullptr) {}
};

struct cmp {
    bool operator()(Node* a, Node* b) {
        return a->w > b->w;
    }
};

void dfs(Node* root, string code, map<char, string>& huff) {
    if (!root) return;
    if (!root->l && !root->r) {
        huff[root->ch] = code;
        return;
    }
    dfs(root->l, code + "0", huff);
    dfs(root->r, code + "1", huff);
}

int main() {
    string s;
    getline(cin, s);
    map<char, int> freq;
    for (char ch : s) freq[ch]++;
    
    priority_queue<Node*, vector<Node*>, cmp> pq;
    for (auto& [ch, w] : freq)
        pq.push(new Node(ch, w));
    
    while (pq.size() > 1) {
        Node* a = pq.top(); pq.pop();
        Node* b = pq.top(); pq.pop();
        Node* p = new Node(0, a->w + b->w);
        p->l = a; p->r = b;
        pq.push(p);
    }
    
    map<char, string> huff;
    dfs(pq.top(), "", huff);
    
    for (auto& [ch, code] : huff)
        cout << ch << ": " << code << '\n';
    return 0;
}
```

### 第 1 题 电报编码（100 分）— <a href="https://fslong.iok.la/problem/P9837" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

在电报通信中，为提升传输效率，需为每个字符设计二进制编码。现给定 n 个字符及其出现频率，请你为每个字符设计哈夫曼编码。

编码规则：左分支为 `0`，右分支为 `1`。构建时每次合并权值最小的两节点；若权值相同，优先合并字符 ASCII 码较小的节点。

**输入格式**

第一行一个整数 n（2 ≤ n ≤ 26），表示字符种类数。

接下来 n 行，每行一个字符 c 和一个整数 f，表示字符及其出现频率。字符为小写英文字母，频率为正整数（1 ≤ f ≤ 1000）。

**输出格式**

对于每个字符，按输入顺序输出一行 `c: code`，表示该字符的哈夫曼编码。

**样例输入**

```
5
a 2
b 3
c 5
d 7
e 9
```

**样例输出**

```
a: 000
b: 001
c: 01
d: 10
e: 11
```

**提示**

可利用优先队列（小根堆）辅助构建哈夫曼树。注意处理权值相同时的选择规则。

**数据范围**

对于 30% 的数据，n ≤ 5。  
对于 60% 的数据，n ≤ 15。  
对于 100% 的数据，2 ≤ n ≤ 26，1 ≤ f ≤ 1000。

### 第 2 题 最小编码长度（100 分）— <a href="https://fslong.iok.la/problem/P9838" target="_blank">🧑‍💻 在线答题</a>

**题目描述**

小明需要将一篇由 n 种不同字符组成的文章进行二进制编码传输。已知每种字符的出现次数，请你计算采用哈夫曼编码时，编码整篇文章所需的**最少二进制位数**（即哈夫曼树的带权路径长度 WPL）。

**输入格式**

第一行一个整数 n（2 ≤ n ≤ 10000），表示字符种类数。

第二行 n 个正整数 a₁, a₂, ..., aₙ，表示每种字符的出现次数（1 ≤ aᵢ ≤ 10⁵）。

**输出格式**

输出一个整数，表示编码整篇文章所需的最少二进制位数。

**样例输入 1**

```
4
7 5 2 4
```

**样例输出 1**

```
35
```

**样例解释 1**

构建哈夫曼树：
- 合并 2+4=6（WPL+=6）
- 合并 5+6=11（WPL+=11）
- 合并 7+11=18（WPL+=18）
- WPL = 6+11+18 = 35

**样例输入 2**

```
5
1 2 3 4 5
```

**样例输出 2**

```
33
```

**提示**

- WPL 即为所有非叶子节点的权值之和
- 可使用 `priority_queue`（小根堆）模拟合并过程
- 注意数据范围，结果可能超过 32 位整数

**数据范围**

对于 30% 的数据，n ≤ 100。  
对于 60% 的数据，n ≤ 1000。  
对于 100% 的数据，2 ≤ n ≤ 10000，1 ≤ aᵢ ≤ 10⁵。
